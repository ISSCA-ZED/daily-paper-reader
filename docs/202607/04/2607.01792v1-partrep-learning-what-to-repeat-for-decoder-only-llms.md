## 摘要
尽管解码器专用大语言模型在大量自然语言任务中表现出色，但因果注意力机制导致其信息流不对称：后续token比前期token拥有更丰富的上下文基础。一种简单有效的补救措施是提示重复——在生成前将提示的副本追加到原始提示之后，可以重新分配不同位置的信息基础并提升推理性能。然而，原始提示的完全重复会使KV缓存占用翻倍，并在预填充阶段将注意力计算成本提升至四倍，因此在长上下文场景中不实用。我们提出PartRep，一种选择性增强方法，仅追加信息量最大的token，而非整个提示。我们以token级负对数似然（NLL）作为选择信号，其动机是：可预测性较低的token更难从周围上下文中恢复，因此更需要后期位置的重复。为避免为评分而进行完整前向传播的高昂成本，我们训练了一个轻量门控网络，从早期层隐藏状态中预测高NLL token，从而通过早期退出实现预填充中期的token选择。在八个基准测试（包括MMLU、GSM8K和RULER）和三个模型系列（Qwen2.5、Llama3.2、Gemma4）上，PartRep保留了完全重复的大部分增益，同时仅使用其59.4%的KV缓存和79.0%的预填充FLOPs。

## Abstract
While decoder-only LLMs excel at a vast array of natural language tasks, it suffers from an asymmetric information flow induced by causal attention: later tokens are richer in contextual grounding than earlier ones. A simple and effective remedy is prompt repetition -- just appending a second copy of prompt before generation can redistribute grounding across positions and improve reasoning performance. However, full repetition of the original prompt doubles the KV cache footprint and quadruples attention cost during prefill, making it impractical for long-context settings. We propose PartRep, a selective augmentation method that appends only the most informative tokens -- rather than the entire prompt. We use token-wise negative log-likelihood (NLL) as a selection signal, motivated by the hypothesis that less predictable tokens are less recoverable from surrounding context and therefore benefit more from late-position repetition. To avoid the heavy cost of a full forward pass for scoring, we train a lightweight gate that predicts high-NLL tokens from early-layer hidden states, enabling token selection during mid-prefill via early exit. Across eight benchmarks (including MMLU, GSM8K, and RULER) and three model families (Qwen2.5, Llama3.2, Gemma4), PartRep retains most of the gains of full repetition while using only 59.4\% of its KV cache and 79.0\% of its prefill FLOPs.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **问题**：Decoder-only 大语言模型（LLM）的因果注意力机制导致信息流不对称：序列末尾的 token 拥有更丰富的上下文，而前期的 token 则缺乏后期的全局信息。这种不对称会引发前提顺序敏感、选项排序偏差和“中间迷失”等问题，限制了模型的推理能力。
- **已有解决方案**：提示重复（Prompt Repetition）——在生成前将整个提示复制一遍并追加到末尾，使得每个原始 token 后面都有一个“回声”token，从而重新分配上下文信息，显著提升推理准确性。然而，全重复使得输入长度翻倍，KV 缓存占用翻倍，预填充阶段自注意力 FLOPs 增至四倍，在长上下文场景中不可持续。
- **本文目标**：在保留提示重复带来性能提升的前提下，大幅降低计算和内存开销。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：并非所有 token 都值得重复，只需重复“信息密度最高”的 token 即可。定义 token 的信息密度为其负对数似然（NLL）：  
  \[
  \text{NLL}(t_i) = -\log P(t_i | t_{<i})
  \]  
  高 NLL 的 token 即“意外”token，其内容难以从上下文恢复，重复它们能带来最大边际收益。
- **选择过程**：使用一个轻量级门控网络（Gate）在预填充中期（早期层隐藏状态）预测 token 的 NLL 排名，从而避免执行完整前向传播。  
  - 门控网络结构：先通过两层 MLP 将隐藏状态映射为查询向量，再与可学习键值进行注意力，输出 sigmoid 概率分数。  
  - 训练：用完整模型的前向传播为每个 prompt 生成 NLL 标签，然后训练门控网络预测哪些 token 属于 top-τ 高 NLL 子集（τ 为重复预算比例）。损失函数使用带类别平衡加权的二分类交叉熵。
- **推理流程**：
  1. 对原始 prompt 进行部分前向传播至指定层（如第 18 层），提取隐藏状态。
  2. 门控网络输出每个 token 的重复概率，选择 top-τ 比例的 token。
  3. 通过自然语言桥接（例如“Pay attention to these key tokens:”）将选中的 token 追加到原始 prompt 之后。
  4. 对扩展后的序列完成完整预填充和生成。
- **可选扩展**：Token Windowing——对于子词分词可能导致语义碎片的情况，可将选中的 token 扩展为包含完整词语或局部上下文窗口。

## 6. 论文的主要结论与发现

- PartRep 在仅使用全重复 59.4% KV 缓存和 79.0% 预填充 FLOPs 的条件下，保留了全重复的大部分精度增益（平均 68.3% vs 全重复 68.5%）。
- 高 NLL token 的选择准则优于随机、低 NLL、注意力、TF-IDF 等准则，支持了“信息密度”假说。
- 轻量门控网络（2 层 MLP + 注意力）在准确性与计算开销之间达到良好平衡。
- Token Windowing（扩展为完整词或局部窗口）可缓解子词分词导致的语义碎片问题。
- 长上下文场景（RULER 4K/8K/16K）中，PartRep 甚至优于全重复，说明选择性重复能避免全重复引入的“中间迷失”。
- 简单自然语言连接词（如“Pay attention to these key tokens:”）比结构化模板（ChatML、XML）更有效。

## 7. 优点：方法或实验设计上的亮点

- **创新性**：首次提出“选择性重复”概念，将问题建模为 token 级重要性选择，与 KV 缓存驱逐（“什么可以丢弃”）形成互补。

- **原则性**：以负对数似然（NLL）作为信息密度的代理，有信息论依据。
- **泛化性**：在三个不同的模型家族（包括混合注意力机制的 Gemma 4）上均有效。
- **实验设计严谨**：同时对比了 KV 缓存占用和 FLOPs，并包括了算法自身开销，能全面评估实际效率。
- **实用性**：无需修改模型架构或参数，仅需训练一个轻量门控即可通用到不同 prompt。
