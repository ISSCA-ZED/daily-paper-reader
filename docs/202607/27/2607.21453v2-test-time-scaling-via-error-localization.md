## 摘要
扩展推理时计算已成为提升大型语言模型在复杂推理和编程任务中性能的可靠方法。然而，独立采样和顺序多轮优化等标准方法在没有令牌级信用分配的情况下运行，导致计算效率低下，因为有效的推理前缀经常被丢弃。在这项工作中，我们引入了通过错误定位的测试时缩放（TTEL），这是一种利用固定或环境反馈执行令牌级错误定位的推理时算法。通过将有信息反馈下的条件概率与无上下文基线进行比较，TTEL 能够隔离发生错误的步骤。然后，该算法截断轨迹并分支生成新内容，最大限度地重用有效前缀。大量评估表明，TTEL 在顺序推理领域建立了严格占主导的帕累托前沿，以 pass-at-k 与生成令牌成本衡量。在 LiveCodeBench 上使用 Qwen3-8B，TTEL 实现了 71.0% 的 pass@64，同时生成的令牌数约为独立采样的一半（360.4k vs 735.0k）。推广到数学基准 AIME-2025 和 HMMT-2025，TTEL 在 Qwen3-8B 和 Qwen3-4B-Thinking-2507 上均明显优于其他测试时基线。

## Abstract
Scaling inference-time computation has emerged as a reliable method to improve the performance of large language models on complex reasoning and programming tasks. However, standard approaches such as independent sampling and sequential multi-turn refinement operate without token-level credit assignment, resulting in computational inefficiency, since valid reasoning prefixes are frequently discarded. In this work, we introduce Test-Time Scaling via Error Localization (TTEL), an inference-time algorithm that utilizes fixed or environment feedback to perform token-level error localization. By comparing conditional probabilities under informed feedback against a null-context baseline, TTEL isolates the step at which an error occurred. The algorithm then truncates the trajectory and branches a new generation, maximally reusing the valid prefix. Extensive evaluations demonstrate that TTEL establishes strictly dominating Pareto frontiers across sequential reasoning domains, measured by pass-at-k vs. generated-token cost. With Qwen3-8B on LiveCodeBench, TTEL attains a pass@64 of 71.0% while generating approximately half as many tokens as independent sampling (360.4k vs. 735.0k). Generalizing to math benchmarks AIME-2025 and HMMT-2025, TTEL cleanly outperforms competing test-time baselines across both Qwen3-8B and Qwen3-4B-Thinking-2507.

  - 树搜索方法（如 Tree-of-Thoughts）依赖粗粒度步骤和外部启发式，未利用 token 级细粒度信号。
- **研究动机**：能否让 LLM 对自身失败轨迹进行 token 级事后信用分配，并利用该信号引导推理时搜索，从而最大化重用正确前缀、只重新生成错误后缀？
- **整体含义**：TTEL 提出一种无需梯度更新的推理时算法，通过比较有信息反馈与无诊断基线下的条件概率差异，定位错误 token，截断轨迹并分支新生成，在编程与数学推理任务上建立了严格占主导的计算-性能帕累托前沿。

## 2. 方法论：核心思想、关键技术细节、算法流程

### 核心思想
- 基于一个预训练语言模型 πθ，同时作为生成器和评估器。
- 核心机制：计算**学生概率**（无反馈下生成 token 的概率）与**教师概率**（附加上环境反馈后重新打分得到的概率）之间的差异，通过对比两套上下文（真反馈 vs 非诊断性空反馈）来过滤噪声，定位真正的错误位置。

### 关键技术细节

#### 2.1 尖峰检测与滤波（Spike Detection & Filtering）
- **学生概率**：p(S)_t = πθ(y_t | x, y_<t)
- **教师概率（真反馈）**：p(T)_t(f) = πθ(y_t | x, y_<t, f)，其中 f 为执行环境返回的反馈（如错误信息、失败测试用例）
- **原始尖峰**：Δ_t(f) = p(S)_t - p(T)_t(f)，正值表示模型在获得反馈后对原 token 选择信心下降
- **非诊断性基线**：引入空反馈 f_∅（例如“重复前一次尝试，跳过冗余思考”），计算基线尖峰 Δ_t(f_∅) = p(S)_t - p(B)_t(f_∅)
- **滤波后尖峰分数**：g_t = Δ_t(f) - Δ_t(f_∅) = p(B)_t(f_∅) - p(T)_t(f)
- **筛选条件**：保留同时满足 Δ_t(f) > τ 且 Δ_t(f_∅) ≤ τ_B 的 token 位置，构成有效错误集 E_filtered。

#### 2.2 搜索与分支策略
- **分支点选择**：t* = argmax_{t∈E_filtered} g_t，即选取最强反馈特异性差异的位置。
- **分支操作**：保留前缀 y_<t*，截断该位置及之后内容，从该前缀重新生成（复用正确部分）。
- **重启机制**：若 E_filtered 为空（无法定位错误），则从根 prompt 重新开始，避免陷入无信息轨迹。

#### 2.3 算法流程（Algorithm 1 文字描述）
1.  初始化树 T = {∅}（保留前缀集合），候选集 S = ∅，反馈 f = ∅。
2.  循环直到达到计算预算 B：
    - 从 T 中选择一个叶子前缀 y_<t（初始为空）。
    - 基于 prompt x + 保留前缀 y_<t + 当前反馈 f 生成完整轨迹 y。
    - 环境 E 返回反馈 f（如编译错误、失败测试等）。
    - 对学生生成的 y 重新打分：
      - 在原始上下文 + 真反馈下得到教师概率，计算 Δ_t(f)。
      - 在原始上下文 + 空反馈下得到基线概率，计算 Δ_t(f_∅)。
    - 根据阈值 τ, τ_B 构建局部错误集 E。
    - 若 E 非空，将分支点 t* 对应的前缀 y_<t* 加入 T；否则清空 T 并重置 f = ∅。
    - 将当前 y 加入候选集 S。
3.  返回 S，可用外部验证器或多数投票选择最终答案。

### 理论分析（Theorem 1）
- 定理表明：在满足自回归前缀一致性假设下，分支策略（从锚定前缀 a 开始生成）相比重启策略（从头生成）的收益为 (1 - p_a)(s_a - s_{¬a})，其中 p_a 是重启自然恢复前缀 a 的概率，s_a 和 s_{¬a 分别是给定前缀或非给定前缀下的成功概率。只要 s_a > s_{¬a}，分支严格优于重启。

## 6. 主要结论与发现

1. **计算-性能帕累托占优**：在 LiveCodeBench、AIME、HMMT 上，TTEL 在所有 token 预算下均达到更高 pass@k，建立严格支配前沿。例如，Qwen3-8B 在 LiveCodeBench 上 pass@64 达 71.0%，仅用独立采样一半 token（360.4k vs 735.0k）。
2. **无需训练**：全部操作在推理时完成，不修改模型权重，可即插即用于任何自回归 LLM。
3. **通用反馈有效**：即使缺少执行环境诊断（如数学题），仅靠通用失败提示也能诱导 token 级概率差异，实现有效定位。
4. **基线滤波必须**：去除空反馈滤波会导致假阳性尖峰暴增（从 19.3 到 486.0），性能下降 6~7%，证明纯概率对比无法区分上下文偏移。
5. **完整轨迹不可少**：只提供最终答案而非完整推理链时，错误定位精度大幅下降（pass@64 从 63.0% 降至 59.7%），确认需保留完整思考过程。
6. **分支优于重启**：理论分析与实验均证明，从保留前缀分支能最大化利用已验证正确部分，避免重复计算。

## 7. 优点

- **方法创新性**：首次将 token 级自蒸馏风格信用分配信号直接用于推理时搜索，无需梯度更新或额外模型，简洁有效。
- **计算高效**：通过前缀重用和精准错误定位，显著降低无效 token 生成，实现 2 倍 token 节约仍提升性能。
- **理论扎实**：提供分支优势定理，形式化证明分支严格优于重启（只要正确前缀成功率高）。
- **实验严谨**：多种子、多基线、多维度消融，帕累托图直观展示 trade-off，消融实验因果清晰。
- **通用性**：对编程和数学两种典型推理场景均有效，且对反馈丰富程度有一定鲁棒性（通用反馈仍有效）。
- **实用性**：可直接与现有推理模型（如 Qwen3、DeepSeek-R1 等）结合，补充其测试时搜索效率。
