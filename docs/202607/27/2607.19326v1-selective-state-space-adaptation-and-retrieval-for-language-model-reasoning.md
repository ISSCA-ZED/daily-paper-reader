## 摘要
低秩适应引入了一种静态学习更新，对每个输入同样应用。该更新提供了任务级别的适应，但并未明确表示令牌级别或实例级别的状态变化。本文提出了一族适配器，在两个互补的粒度上引入了选择性状态空间递归。在令牌级别，\textbf{MaLoRA}（Mamba调制低秩适应）使适配器的缩放因子成为具有跨令牌递归状态的动态输入相关函数，这与先前工作的无状态调制器不同。在上下文级别，\textbf{MaRA}（Mamba检索适配器）跟踪跨段状态，并在调制语言模型生成答案之前选择与查询最相关的段。在三个冻结骨干网络（Qwen-2.5-7B、Llama-3.1-8B、Gemma-2-9B）和两个推理基准（MuSiQue、2WikiMultihopQA）上，该族在$3\times2$网格的每个单元格上提高了推理准确率，平均超过LoRA基线+6.8 F1（相对+10.5%），在最困难的单元格上最高达+9.3 F1（相对+18.2%），并且令牌级别的增益在长度压力下的RULER QA-2上仍然保持。

## Abstract
Low-rank adaptation introduces a static learned update applied identically to every input. The update provides task-level adaptation but does not explicitly represent token-level or instance-level state variation. A family of adapters is proposed that introduces selective state-space recurrence at two complementary granularities. At the token level, \textbf{MaLoRA} (Mamba-modulated low-rank adaptation) makes the adapter's scaling factor a dynamic input-dependent function with recurrent state across tokens, in contrast to the stateless modulators of prior work. At the context level, \textbf{MaRA} (Mamba Retrieval Adapter) tracks cross-segment state and selects the segments most relevant to the query, before the modulated language model generates its answer. Across three frozen backbones (Qwen-2.5-7B, Llama-3.1-8B, Gemma-2-9B) and two reasoning benchmarks (MuSiQue, 2WikiMultihopQA), the family improves reasoning accuracy on every cell of the $3{\times}2$ grid, by $+6.8$ F1 ($+10.5\%$ relative) on average and up to $+9.3$ F1 ($+18.2\%$ relative) on the hardest cell over the LoRA baseline, and the token-level gains carry to RULER QA-2 under length stress.

# 论文总结：Selective State-Space Adaptation and Retrieval for Language Model Reasoning

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：低秩适配（LoRA）为冻结的语言模型提供静态的任务级更新，对所有输入应用相同的参数变化。然而，多步推理等任务涉及多种潜在状态（如不同 token 角色、多段落证据），静态更新无法捕捉 token 级或实例级的状态变化，限制了模型的推理适应性。
- **目标**：在不调整骨干网络的前提下，使适配器能够根据输入状态进行动态、自适应调整，同时保持参数高效。
- **整体含义**：将选择性状态空间模型（SSM）引入参数高效微调领域，分别在 token 粒度和上下文段落粒度引入递归状态，实现更精细的推理适应，从而显著提升冻结大模型在多跳问答上的表现。

## 2. 方法论

### 2.1 核心思想
- 在 **token 级** 和 **context 级** 两个互补粒度上使用相同的 Mamba（SSM）模块，但作用不同：
  - **token 级**：MaLoRA，让 LoRA 的缩放因子变为一个依赖输入历史（递归状态）的动态标量，而非 stateless 的逐 token 标量。
  - **context 级**：MaRA，利用 SSM 在段落嵌入序列上运行递归，跟踪跨段状态并选择与查询最相关的段落，再让调制后的语言模型进行生成。

### 2.2 关键技术细节

#### (a) MaLoRA（Mamba-modulated Low-Rank Adaptation）
- 将 TopLoRA 的无状态对角门替换为**有状态标量门**：
  - 输入 xₜ → 低秩投影 Pxₜ → Mamba 模块（保持隐藏状态 sₜ，状态更新依赖于输入和学习参数）→ 输出 oₜ → 小头 ϕ → softplus 得到 λ(xₜ) 标量（>0）。
  - 输出 hₜ = (W₀ + B·λ(xₜ)·A)·xₜ，其中 λ(xₜ) 可同时放大（>1）或压制（<1）LoRA 更新。
  - Mamba 的递归使得 λ(xₜ) 依赖于 token 序列的轨迹，而不是仅当前 token。
- **参数效率**：MaLoRA 仅增加约 50% 的 LoRA 参数量（与 TopLoRA 的 54% 接近）。

#### (b) MaRA（Mamba Retrieval Adapter）
- 四个阶段：
  1. **段落编码器**：将每个段落 Cᵢ 与查询 Q 拼接，用冻结骨干的前 K=16 层编码，得到隐藏状态 Hᵢ（无新增编码器参数）。
  2. **注意力池化**：学习查询向量 qₐ，对每个段落的隐藏状态做注意力加权求和，得到段落嵌入 pᵢ。
  3. **跨段 Mamba**：将段落嵌入序列 (p₁,…,p_N) 输入两层 Mamba，递归单元是段落（而非 token），产生递归状态 sᵢ。
  4. **评分头**：局部头从每个 sᵢ 输出评分 rᵢ（用于 top-k 选择）；全局头从最终状态 s_N 预测所有段落的标签（辅助损失）。
- **训练损失**：加权二元交叉熵（局部）+ 成对边际损失（推动支持段落评分高于非支持）+ 辅助全局 BCE（γ=0.5）。
- **推理**：采用迭代选择（Algorithm 1），对 2WikiMultihopQA 进行 2 次迭代，对 MuSiQue 进行 4 次迭代，逐步选择最相关的段落作为锚点，最终按评分排序取 top-k。

#### (c) 组合使用
- MaLoRA 在 LM 内部修改权重更新，MaRA 在 LM 外部重排输入上下文；两者作用互补，增益可叠加而非重叠。

## 6. 主要结论与发现

- **主结果**：MaLoRA+MaRA 系统在 3×2 网格的每个单元格上均优于 LoRA，平均 F1 提升 +6.8（相对 +10.5%），最难的单元格（MuSiQue + Qwen）提升 +9.3 F1（+18.2%）。
- **互补性**：token 级调制按 token 角色（标记、查询、正文）调整 LoRA 更新（角色敏感但段落级别无关），context 级检索按段落相关性选择证据；两者贡献通道不同，增益可叠加（约 18% 的重叠）。
- **检索优势**：MaRA（模型附着的检索）优于外部检索方法（BM25、Qwen3-Embedding 等），尤其是在 MuSiQue 上（Recall@4=80.6 vs 75.5）。
- **长度稳健性**：MaLoRA 在 4k 上下文压力下仍保持提升（RULER QA-2）。
- **参数效率**：MaLoRA 训练时间与 LoRA 基本持平（+7%），远低于 DoRA（+88%）；MaRA 参数仅约 3.1M，训练时间 2.5 h。

## 7. 优点

- **创新性**：首次将选择性状态空间模型（Mamba）作为参数高效适配器的内部门控机制，在 token 和 context 两个粒度上实现动态、记忆性的适应。
- **实验严谨性**：
  - 多骨干、多数据集、多种子。
  - 与多种基线（静态、无状态调制、外部检索）进行公平对比。
  - 丰富的消融实验验证各个设计选择。
- **效率**：MaLoRA 的训练开销远低于 DoRA，与 LoRA 相仿；MaRA 训练轻量且不改变主模型。
- **深入分析**：通过调制行为分析（token 区域均值、方差分解）、状态使用探针等，揭示模型内部工作机制，增强了方法的可解释性。
