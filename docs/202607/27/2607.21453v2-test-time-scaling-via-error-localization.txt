# Test-Time Scaling via Error Localization 

Rajiv Shailesh Chitale, Rahul Madhavan, Taneesh Gupta, Deepanway Ghosal, Aravindan Raghuveer 

Google DeepMind 

## Abstract 

Scaling inference-time computation has emerged as a reliable method to im-prove the performance of large language models on complex reasoning and programming tasks. However, standard approaches such as independent sampling and sequential multi-turn refinement operate without token-level credit assignment, resulting in computational inefficiency, since valid reasoning prefixes are frequently discarded. In this work, we introduce Test-Time Scaling via Error Localization (TTEL), an inference-time algo-rithm that utilizes fixed or environment feedback to perform token-level error localization. By comparing conditional probabilities under informed feedback against a null-context baseline, TTEL isolates the step at which an error occurred. The algorithm then truncates the trajectory and branches a new generation, maximally reusing the valid prefix. Extensive evaluations demonstrate that TTEL establishes strictly dominating Pareto frontiers across sequential reasoning domains, measured by pass-at-k vs. generated-token cost. With Qwen3-8B on LiveCodeBench, TTEL attains a pass@64 of 71.0% while generating approximately half as many tokens as independent sampling (360.4k vs. 735.0k). Generalizing to math benchmarks AIME-2025 and HMMT-2025, TTEL cleanly outperforms competing test-time baselines across both Qwen3-8B and Qwen3-4B-Thinking-2507. 

## 1 Introduction 

Scaling inference-time computation improves the performance of LLMs on complex reason-ing and programming tasks (Snell et al., 2024; DeepSeek-AI, 2025). The main approach for this is to generate multiple independent samples and select the best candidate via majority voting (Wang et al., 2023) or verification against test cases (Jain et al., 2024). While such best-of-K strategies reliably improve accuracy as K increases, they scale inefficiently: each sample is generated without knowledge of prior attempts, leading to redundant exploration of similar trajectories. For problems that require long reasoning chains, where a single early error invalidates the entire generation, this redundancy is wasteful. Sequential multi-turn generation attempts to address this by incorporating environmental feedback into the context window (Madaan et al., 2023). The model generates a subsequent attempt conditioned on the failure of its previous output. However, sequential refinement often stagnates: when faced with genuinely difficult reasoning challenges, models frequently repeat similar logical errors across turns or fail to identify the precise point where the logic diverged (Kumar et al., 2024). The context window fills with unsuccessful attempts without yielding a correct solution. A deeper issue is that post-hoc feedback is inherently trajectory-conditional . When a candidate solution fails, the resulting feedback, such as an environment generated error, or self-generated critique, is informative about the specific reasoning path that produced that failure. If a model is restarted from scratch, it may never revisit the same intermediate states at which the feedback is most relevant. This creates a fundamental mismatch: the supervision is path-specific, but existing inference-time strategies such as sequential refinement largely apply it as though it were a global revision signal. Tree-structured search methods, such as Tree of Thoughts (Yao et al., 2023), offer an alter-native by exploring multiple reasoning paths and backtracking. These methods typically operate at the level of coarse reasoning steps, relying on self-evaluation heuristics to prune

Both families of methods improve over flat sampling, but neither leverages fine-grained, token-level signals about where reasoning went wrong. Essentially, these existing approaches either lose the state on which feedback is informative, or preserve the state without extracting a precise corrective signal from it. This suggests a more targeted view of inference-time improvement: rather than treating feedback as a generic instruction for a fresh retry, can a model use feedback to localize error on the specific trajectory that produced it , retain the useful prefix of that trajectory, and selectively regenerate only the suffix where the reasoning becomes suspect? Motivated by this question, we investigate the following core problem: 

Can an LLM perform token-level credit assignment on its own failed trajectories, and leverage this localized signal to guide test-time scaling optimally? 

We propose TTEL, an inference-time search algorithm that performs token-level error localization without gradient updates. When a generated solution fails, we prompt the model with the environmental feedback to re-evaluate the original trajectory via prompt log-probabilities. By comparing token probabilities before and after observing this feedback, we identify positions of maximal disagreement. A sharp drop in probability indicates that the model strongly rejects its prior decision at that specific step. To ensure these probability shifts are genuinely driven by the feedback rather than generic context changes, we filter the signal against a baseline with non-diagnostic feedback. TTEL then uses this localized signal to truncate the reasoning trace at the highest-confidence error and branch a new generation from that point. By directing computation toward correcting specific mistakes rather than regenerating entire solutions, this feedback-guided tree search achieves substantially higher token efficiency than standard sampling baselines across diverse reasoning tasks, including competitive programming (Jain et al., 2024) and complex mathematical reasoning (Balunovic et al., 2025). 

Our Contributions. Primarily, this paper shows that LLMs can error correct failing trajec-tories at inference time based on feedback, and use it to guide test-time search. Specifically: 

1. Token-Level Error Localization: We introduce TTEL, an inference-time algorithm that uses probability contrasts by comparing informed environmental feedback against non-diagnostic feedback to localize errors during generation. 

2. Efficient Test-Time Search: By coupling local credit assignment with trajectory retention, TTEL truncates and branches only the faulty suffix of a trajectory. This maximizes the reuse of valid reasoning prefixes and eliminates the redundant exploration. 

3. Empirical Efficiency: We establish strictly dominating Pareto frontiers across math benchmarks like AIME-2025, and coding benchmarks like LiveCodeBench where TTEL attains pass@64 of 71.0% at roughly half the token cost of independent sampling. 22 Related Work 

We provide an abbreviated overview of related work below; an extended discussion map-ping TTEL to the broader literature is available in Appendix A. 

Test-Time Scaling and Tree Search. Reasoning performance scales reliably with inference-time compute (Snell et al., 2024; DeepSeek-AI, 2025), typically through robust independent sampling arrays (Wang et al., 2023). To iterate beyond flat sampling, sequential refinement methods prepend execution feedback to prompt self-correction (Madaan et al., 2023; Klis-sarov et al., 2026). However, because they treat trajectory-specific feedback as a global instruction, these models often regenerate reasoning from scratch, triggering context bloat or hallucinated logic (Kumar et al., 2024). Structured backtracking algorithms like Tree of Thoughts (Yao et al., 2023) and population-based search (Venkatraman et al., 2025) remedy this by exploring partial branches, but they rely on programmatic chunking and external heuristics rather than internal, token-level signals. 

On-Policy Distillation and Preference Optimization. Recent work has increasingly uti-lized natural language assessment for dense credit assignment. By evaluating the ratio between a base policy and a feedback-conditioned teacher, methods like Generalized Knowl-edge Distillation (Agarwal et al., 2024) and On-Policy Self-Distillation (Zhao et al., 2026) optimize student models directly on their own generated rollouts. This core mathematical insight, minimizing the Kullback-Leibler divergence driven by πθ (· | x)/πθ (· | x, f ), has established the foundation for new reinforcement learning algorithms, most notably Self-Distillation Policy Optimization (SDPO; H ¨ubotter et al. 2026) and RLTF (Song et al., 2026). Similar mechanisms have also been applied successfully in experiential context distillation (OPCD; Ye et al. 2026) and continual learning (SDFT; Shenfeld et al. 2026). 

Repurposing the Signal for Inference-Time Search. Crucially, this existing body of work restricts the application of the πθ (· | x)/πθ (· | x, f ) divergence to offline gradient updates, yielding static policy networks. The direct capability of this ratio to localize errors purely as an online, inference-time heuristic has remained fundamentally unaddressed. TTEL bridges this gap by repurposing the token-level signal used in the SDPO framework. Specifically, TTEL extracts an organic, native pruning criterion that structures and bounds test-time search without requiring parameter updates.

Takeaway 

Branching structurally guarantees that the generation is anchored exactly where the feedback’s correction becomes actionable. It strictly improves over sequential restart as long as success is more likely once the correct prefix is reached ( sa > s¬a). 

## 7 Experiments 

In this section, we outline our experimental framework designed to evaluate the effective-ness of our proposed method, TTEL. We focus our evaluation on two challenging domains demanding multi-step planning: complex mathematical reasoning and code generation. Our empirical evaluation is designed to answer the following core research questions (RQ): • RQ1 (Compute Scalability & Generalization): How efficiently does TTEL scale inference-time compute to uncover correct trajectories compared to standard multi-turn paradigms, and does this scaling advantage generalize across environments with and without explicit verification feedback? • RQ2 (The Role of Context in Error Localization): How strictly does accurate token-level credit assignment depend on the availability of rich environment execution signals and the retention of the historical reasoning trace? • RQ3 (Filtering Noise vs. Semantic Signal): Is the null-feedback baseline subtraction strictly necessary to isolate genuine, feedback-driven model corrections from generic context-induced probability shifts? 

Evaluation Benchmarks To rigorously assess the capabilities of our approach, we focus on the following two benchmark categories: • Mathematical Reasoning: We evaluate on AIME-25 dataset, and HMMT-25 from the MathArena benchmark (Balunovic et al., 2025). Each dataset consists of 30 highly challeng-ing, competition-level mathematics problems designed to test deep, multi-step analytical reasoning without intermediate execution feedback. • Code Generation: We utilize LiveCodeBench (Jain et al., 2024), specifically a recent subset of 131 contest-style coding questions released between February and May 2025. This benchmark optionally provides rigorous execution feedback via public test cases. We define two variants for our method based on the feedback: • TTEL-GenFB: This uses generic feedback which includes previous answers, the full reasoning trace for the last attempt, a static error message (“Your previous attempt was unsuccessful.”) and a re-attempt instruction. This is applicable for all benchmarks. • TTEL-EnvFB: The static error message in TTEL-GenFB is replaced by rich environ-ment feedback such as runtime errors or failing public test cases. This can be tested on LiveCodeBench as it provides execution based feedback, but not on maths benchmarks. 

Implementation Details We utilize the Qwen3-8B and Qwen3-4B-Thinking-2507 models for our experiments. To compare inference-time scaling across methods, we report both the rollout budget k and the total number of generated tokens . The maximum generation limit per attempt is capped at 16,384 tokens. Decoding across all methods uses a temperature 

T = 1 and top p = 1. For TTEL, we use a localized spike detection threshold of τ = 0.06 and maintain a maximum checkpoint depth of Dc = 16, 384. To standardize evaluation, our primary metric is pass@ k, measuring whether at least one of the k adaptively generated rollouts produces a correct solution. 7Baselines To isolate the performance gains of TTEL, we compare our method against three robust test-time scaling baselines: 1. Independent Sampling: A standard parallel generation (best-of-k) approach. The model independently generates k full rollouts, and we evaluate whether any trajectory success-fully solves the problem. 2. Multi-turn Refinement: A sequential feedback-driven approach. The model is allowed a maximum of k interactive turns to arrive at the correct answer, where each subsequent attempt is conditioned on the full sequence of previous attempts and their respective execution feedback. 3. Recursive Self-Aggregation (RSA): A recent population-based test-time scaling algo-rithm that searches through a parameter space characterized by population size N,aggregation size K, and a distinct number of sequential steps T.

8.2 The Role of Context in Error Localization (RQ2) 

Accurate token-level credit assignment depends on the context provided to the teacher during spike detection. We hypothesize that retention of the original thought trace y, and the specificity of the external feedback f can enable more precise error-localization. As illustrated in Figure 7, blinding the teacher to the Full Trace generated by the student and conditioning execution failure solely on the extracted final answer causes a severe drop in pass@ k (from 0.630 to 0.597 in case of TTEL-GenFB ) alongside inflated token consumption. Accurate mistake localization algebraically requires the model to review the logic that actu-ally produced the error, rendering the Full Trace strictly necessary. Furthermore, advancing beyond generic feedback by injecting explicit execution traces aggressively grounds the probability distribution. ## A Extended Related Work 

Inference-time scaling via sampling, reranking, and verifier selection. The capability of large language models on complex reasoning and programming tasks scales predictably with inference-time compute (Snell et al., 2024; Brown et al., 2024; Wu et al., 2024; Muen-nighoff et al., 2025; DeepSeek-AI, 2025). The most straightforward and robust baseline in this family is independent parallel sampling, where massive arrays of complete candidates are generated and evaluated under specific scaling laws (Brown et al., 2024). Techniques such as pass@ k, Best-of-K, majority voting, and verifier reranking (Lightman et al., 2023) attempt to select the optimal solution from this generated pool. While these methods reliably convert increased test-time compute into higher accuracy, they are fundamentally limited by redundancy: they generate multiple full candidates entirely independently, failing to reuse trajectory-specific feedback or preserve valid partial progress from failed attempts. 

Chain-of-thought prompting and structured reasoning elicitation. Chain-of-Thought (CoT) prompting (Wei et al., 2022) revealed that eliciting explicit intermediate reasoning steps dramatically improves language model performance on complex multi-step tasks. Self-Consistency (Wang et al., 2023) extends this paradigm by sampling diverse CoT reason-ing paths and aggregating via majority vote, effectively combining qualitative reasoning structure with parallel sampling. Further refinements include complexity-based prompting, which preferentially selects more elaborate reasoning chains (Fu et al., 2022); Program-of-Thought prompting, which externalizes computational steps to code interpreters (Chen et al., 2022; Gao et al., 2023); and active prompting, which strategically selects the most informative exemplars to elicit stronger chains (Diao et al., 2024). These methods collec-tively establish that the structure and quality of reasoning is often the critical determinant of test-time performance. TTEL deepens this insight: rather than eliciting better reasoning through prompt engineering, it uses a feedback-conditioned token-level signal to diagnose precisely where reasoning quality degrades and surgically branches from that exact locus. 

Sequential refinement and interactive feedback at inference time. To address the in-efficiency of independent sampling, sequential refinement methods prepend execution feedback to prompt the model to iteratively correct its own errors (Madaan et al., 2023). Recent work investigates interactive in-context learning from natural language feedback as a distinctly trainable capability (Klissarov et al., 2026). While these approaches successfully leverage environmental critiques, the setting remains fundamentally multi-turn in-context learning. Treating trajectory-specific feedback as a global instruction for a sequential retry forces the model to regenerate the reasoning chain from scratch, frequently resulting in context bloat, hallucination, or the repetition of earlier logical errors (Kumar et al., 2024). TTEL mitigates this by using feedback not for an unanchored sequential retry, but for prefix-anchored branching. 

Tree search and structured exploration over reasoning traces. To overcome the limita-tions of sequential generation, backtracking algorithms such as Tree of Thoughts (Yao et al., 2023) and Language Agent Tree Search (Zhou et al., 2023) explicitly structure inference as a search space over partial reasoning trajectories. Population-based and evolutionary methods, including Recursive Self-Aggregation (Venkatraman et al., 2025) and AlphaE-volve (Novikov et al., 2025), scale this by iteratively mutating and recombining successful reasoning paths to discover complex solutions. These methods establish language model inference as a formal search procedure. Concurrently, inference-time control algorithms explicitly optimize computational budgets utilizing explicit constraints, either by deploying verifiable testing mechanisms and adaptive early-stopping criteria to dynamically bound 14 test-time horizons (Gupta et al., 2025a), or by applying simpler sequential budget-forcing sequences (Muennighoff et al., 2025). However, a primary computational bottleneck across these tree-search and explicit control frameworks remains their reliance on manual, coarse-grained chunking, heuristic bounds, or whole-trajectory mutation: they divide generation into heuristically defined “steps” and evaluate states using external value functions. TTEL is fundamentally a tree-search method, but one whose branching rule emerges organically from feedback-conditioned token disagreement rather than hand-designed programmatic search heuristics or blind mutation. 

Verifier-guided reasoning, execution feedback, and program repair. In domains such as competitive programming and mathematical reasoning, execution environments provide rich diagnostic feedback, including runtime errors and public test case outputs (Jain et al., 2024). Previous literature in automated program repair and verifier-guided generation uses this execution feedback primarily to score, rerank, or prompt complete revisions of generated candidates. A key contrast of our work is that TTEL utilizes verifier feedback not merely to evaluate candidates, but to explicitly decide where to truncate the trajectory and branch a new attempt. 

Process reward models and step-level credit assignment. Outcome reward models assign a single scalar to complete solutions, limiting their capacity for localizing errors within multi-step reasoning traces. Process reward models (PRMs) address this gap by providing step-level supervision, either through human annotation (Lightman et al., 2023; Uesato et al., 2022) or automated Monte Carlo estimation procedures such as Math-Shepherd (Wang et al., 2024) and OmegaPRM (Luo et al., 2024). Causal reward modelling techniques such as CROME (Srivastava et al., 2025), RRM (Liu et al., 2024) and CARMO (Gupta et al., 2025b) also attempt to address credit assignment through causal perturbations. The key limitation is that PRMs require training, introducing additional annotation costs and potential distribution mismatch when applied to new domains or model families. TTEL achieves analogous credit assignment, but derives its signal purely from the probabilistic disagreement between the base and feedback-conditioned policies, requiring no externally trained reward model. 

On-policy distillation and learning from self-generated trajectories. Because environ-ment verifiers typically provide only terminal outcomes, minimizing the distribution mis-match between training and inference requires on-policy algorithms. Generalized Knowl-edge Distillation (GKD) trains the student model on its own generated output sequences while leveraging feedback from the teacher, preventing off-policy divergence (Agarwal et al., 2024). Similarly, On-Policy Self-Distillation (OPSD) utilizes a single model acting as both teacher (conditioned on privileged verified reasoning traces) and student, minimizing the divergence over the student’s own rollouts (Zhao et al., 2026). These highly relevant methods learn directly from the model’s own trajectories, but they internalize the signal into model parameters through offline training, rather than dynamically guiding inference-time branching on the current problem instance. 

Self-distillation and RL from rich textual feedback. Recent advancements have for-malized reinforcement learning protocols capable of exploiting rich, textual environment feedback to overcome the scalar credit assignment bottleneck. Self-Distillation Policy Op-timization (SDPO) converts tokenized feedback into a dense learning signal by treating the feedback-conditioned model as a self-teacher, distilling its next-token predictions back into the policy (H ¨ubotter et al., 2026). Concurrently, RLTF explores self-distillation and feedback-modeling objectives to internalize multi-turn textual critique for improved single-turn test-time performance (Song et al., 2026). Conceptually, these works are the closest to our approach, as they utilize textual critique for dense token-level credit assignment. However, they primarily improve the policy through offline training. TTEL demonstrates that similar token-level divergence signals can be repurposed to guide search organically 

without gradient updates. 

Training for extended reasoning via reinforcement learning. A parallel line of work focuses on training models to produce longer, more deliberate reasoning traces. STaR (Zelik-15 man et al., 2022) and V-STaR (Hosseini et al., 2024) bootstrap reasoning ability by iteratively fine-tuning on self-generated correct rationales. At larger scale, Gemini 2.5 (Comanici et al., 2025) employs reinforcement learning to produce extended internal chains of thought, while DeepSeek-R1 (DeepSeek-AI, 2025) demonstrates that RL with verifier rewards can elicit sophisticated emergent behaviors including self-verification and backtracking. GRPO (Shao et al., 2024) and related group-relative policy optimization methods reduce the need for explicit critic models in this setting. These training-time investments produce reasoning models whose outputs are naturally amenable to test-time scaling interventions. TTEL is complementary to this paradigm: it operates purely at inference time on any model capable of generating reasoning traces, requiring no additional training or parameter updates, and can be composed with RL-trained reasoning models to further improve their test-time search efficiency. 

Context distillation and internalizing auxiliary information into weights. Context distil-lation methods aim to convert useful but cumbersome context, such as optimized system prompts, retrieval augmentations, or historical traces, directly into model parameters. For instance, On-Policy Context Distillation (OPCD) bridges on-policy learning with context dis-tillation by training student models on generated trajectories to match a context-conditioned teacher (Ye et al., 2026). TTEL is related to this paradigm in spirit, as it also leverages the auxiliary information provided by prior attempts and environment feedback. However, rather than absorbing that information offline to permanently update weights, TTEL uses the auxiliary feedback online to evaluate and anchor the search at a securely retained prefix. 

Self-distillation beyond post-training: demonstrations and continual learning. The utility of on-policy self-distillation extends beyond reasoning verification. Self-Distillation Fine-Tuning (SDFT) establishes it as a powerful recipe for continual learning from demon-strations, leveraging a demonstration-conditioned model as an on-policy teacher to acquire new skills while avoiding catastrophic forgetting (Shenfeld et al., 2026). While less directly fo-cused on verifier-guided reasoning, SDFT highlights that context-conditioned self-teaching signals are part of a broader, highly effective algorithmic trend. TTEL positions itself within this trend, uniquely distinct by deploying the self-teaching signal purely at inference time. 

Overthinking, reasoning efficiency, and adaptive compute allocation. As reasoning models generate increasingly long chains of thought, the problem of overthinking expending substantial compute on problems solvable with far less deliberation has emerged as a practi-cal concern (Chen et al., 2024; Gupta et al., 2025a). Adaptive compute allocation methods seek to match reasoning effort to problem difficulty, for instance through early-exit mecha-nisms, confidence-based stopping criteria, or learned allocation policies. TTEL’s spike-based branching mechanism naturally addresses this inefficiency: by localizing errors to specific token positions via feedback-conditioned disagreement, it preserves demonstrably correct reasoning prefixes and avoids redundant regeneration of already-valid computation. This prefix-anchored branching strategy ensures that test-time compute is concentrated pre-cisely where reasoning fails, rather than distributed uniformly or wastefully across the full trajectory. 

Summary of Positioning. In summary, TTEL lies at the intersection of verifier-guided inference-time scaling, token-level self-distillation-style credit assignment, and structured tree search. Its distinguishing conceptual feature is that it couples feedback-conditioned credit assignment with retained-prefix branching on the exact failed trajectory. By doing so, it transcends the limitations of methods that utilize feedback exclusively for outcome reranking, unanchored multi-turn retries, or static offline parameter updates.
