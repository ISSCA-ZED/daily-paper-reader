## Abstract
Large language models (LLMs) have demonstrated remarkable reasoning capabilities in math and coding, often bolstered by post-training on the chain-of-thoughts (CoTs) generated by stronger models. 
However, existing strategies for curating such training data predominantly rely on heuristics, limiting generalizability and failing to capture subtleties underlying in data. 
To address these limitations, we leverage influence functions to systematically attribute LLMs' reasoning ability on math and coding to individual training examples, sequences, and tokens, enabling deeper insights into effective data characteristics.
Our Influence-based Reasoning Attribution (Infra) uncovers nontrivial cross-domain effects across math and coding tasks: high-difficulty math examples improve both math and code reasoning, while low-difficulty code tasks most effectively benefit code reasoning.
Based on these findings, we introduce a simple yet effective dataset reweighting strategy by flipping task difficulty, which doubles AIME24 accuracy from 10\% to 20\% and boosts LiveCodeBench accuracy from 33.8\% to 35.3\% for Qwen2.5-7B-Instruct.
Moreover, our fine-grained attribution reveals that the sequence-level exploratory behaviors enhance reasoning performance in both math and code, and the token-level influence patterns are distinct for math and code reasoning: the former prefers natural language logic connectors and the latter emphasizes structural syntax.

- **研究动机**：大型语言模型（LLM）在数学和代码推理上表现出色，通常依赖于在更强模型生成的思维链（CoT）上进行后训练。然而，现有训练数据筛选策略主要基于**启发式方法**（如关键词、长度、难度经验判断），无法捕捉数据中微妙的特性，且泛化性受限。

- **整体含义**：本文通过**影响函数**（Influence Functions）将推理能力系统地归因到单个训练样本、序列和token，从因果角度揭示数据特性，并为数据优化提供可解释的指导。

## 2. 方法论：核心思想、关键技术细节
- **核心思想**：利用影响函数估计训练样本对模型在正确样本上的对数似然（代理目标函数）的影响，从而识别促进推理的关键数据。
- **关键技术细节**：
  - **代理目标函数**：`f(θ) = (1/n) Σ log p(y_i | x_i; θ)`，其中`(x_i, y_i)`为正确回答的样本。
  - **实例级影响分数**：`If(z_m) = -∇f(θ)^T H^{-1} ∇L(z_m, θ)`，其中`H`为Hessian矩阵，使用**EK-FAC**近似（仅考虑MLP参数，忽略注意力层）以降低计算复杂度。
  - **序列级影响分数**：通过**反事实删除**某句子`y`：`If(y) = If(z_m) - If(z\y_m)`，衡量该句子的边际贡献。
  - **token级影响分数**：利用自回归分解：`∇L(z_m, θ) = Σ_t -∇log p(z_{m,t} | z_{m,<t}, θ)`，进而得到每个token的影响。
- **算法流程**（文字说明）：
  1. 使用SFT训练模型。
  2. 收集正确回答的验证样本，计算`f(θ)`。
  3. 对每个训练样本计算梯度，利用EK-FAC估计Hessian逆，计算影响分数。
  4. 按分数排序，分析高影响样本的领域、难度、行为模式及token特性。

## 6. 论文的主要结论与发现
1. **跨领域影响**：代码数据对数学有非平凡贡献，数学数据对代码也有贡献；**符号化、高形式化的数学（如FOBAR类型、大学级别）更有利于代码推理**。
2. **难度的影响**：
   - 高难度数学数据同时对数学和代码推理有益。
   - 低难度代码数据对代码推理最有效（结合数学数据时）。
   - 最优策略：**高难度数学 + 低难度代码**。
3. **难度翻转策略有效性**：Qwen2.5-7B上AIME24从10%提升至20%，LiveCodeBench从33.8%升至35.3%；14B模型也有提升。
4. **序列层发现**：**探索行为**（在得到正确后仍寻找其他方法）对数学和代码推理均有正面影响，且强于验证行为。先前研究中常被视为“过度思考”的行为实际上有益。
5. **token层发现**：
   - **数学推理**：高影响token为自然语言逻辑连接词（Wait, However, Hence, Therefore等）。
   - **代码推理**：高影响token为结构语法标记（### Solution、```bash、def (self, A: List[int]) -> int:等）。
   - 差异解释了为何结构清晰的简单代码与数学逻辑结合更有效。

- **实用价值**：基于归因发现提出简单的数据重加权策略，显著提升性能，证明归因结果的可迁移性。
