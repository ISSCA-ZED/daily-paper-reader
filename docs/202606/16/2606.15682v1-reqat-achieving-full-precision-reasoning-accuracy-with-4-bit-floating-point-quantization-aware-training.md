## 摘要
大型推理模型（LRMs）通过长思维链实现了强大的问题解决能力，但其部署受到全精度推理成本高昂和KV缓存占用不断增长的制约。微尺度FP4格式使得高效的FP4部署成为可能；然而，对权重、激活和KV缓存进行全面量化（W4A4KV4）会导致严重的推理性能下降，而现有的PTQ和QAT方法无法恢复。我们发现FP4的失败集中在低熵token上——即精确的符号承诺，如数字和运算符——量化噪声会放大采样误差，这些误差会通过推理轨迹级联传播。基于这一洞察，我们提出了ReQAT，一个以推理为中心的FP4训练框架，包含三个组件：（i）轨迹对齐QAT（TAQ），它重新审视相同的推理轨迹，将更新集中在关键的低熵决策上；（ii）选择性熵最小化（SEM），它增强低熵位置的置信度；以及（iii）Q-FIT，一种量化友好的初始化方法，联合校准与RoPE一致的KV缓存变换，以稳定QAT。在相同的训练预算下，ReQAT不仅恢复而且超越了BF16微调的精度，同时在NVIDIA DGX Spark上实现了高达3.9倍的吞吐量加速，在B200上实现了3.1倍的加速。

## Abstract
Large Reasoning Models (LRMs) achieve strong problem-solving through long chain-of-thought, but their deployment is constrained by the high cost of full-precision inference and growing KV cache footprints. Microscaled FP4 formats enable efficient FP4 deployment; however, fully quantizing weights, activations, and KV caches (W4A4KV4) causes severe reasoning degradation that existing PTQ and QAT fail to recover. We identify that FP4 failures concentrate on low-entropy tokens--precise symbolic commitments such as digits and operators--where quantization noise inflates sampling errors that cascade through reasoning traces. Based on this insight, we propose ReQAT, a reasoning-centric FP4 training framework with three components: (i) Trace-Aligned QAT (TAQ), which revisits identical reasoning traces to focus updates on critical low-entropy decisions; (ii) Selective Entropy Minimization (SEM), which reinforces confidence at low-entropy positions; and (iii) Q-FIT, a quantization-friendly initialization that jointly calibrates RoPE-consistent KV cache transformations to stabilize QAT. Under the same training budget, ReQAT not only recovers but surpasses BF16 fine-tuning accuracy, while delivering up to 3.9x throughput speedup on NVIDIA DGX Spark and 3.1x on B200.

# ReQAT: 论文总结

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：大型推理模型（LRMs）通过长链式思维（CoT）实现强推理能力，但其部署受限于全精度推理的高成本以及 KV 缓存的快速增长。微尺度 4-bit 浮点格式（如 MXFP4、NVFP4）在硬件支持（NVIDIA Blackwell）下可实现高效推理，但完全量化（权重、激活、KV 缓存均为 FP4，即 W4A4KV4）会导致严重的推理精度下降。
- **核心问题**：现有的后训练量化（PTQ）和量化感知训练（QAT）方法无法恢复 W4A4KV4 下的推理精度，精度差距持续存在，甚至低于 BF16 基线。
- **整体含义**：首次揭示了 FP4 量化失败集中在**低熵 token**（如数字、运算符等精确符号承诺），这些 token 的量化噪声会放大采样误差，并通过推理轨迹级联传播。为此提出 ReQAT 框架，在相同训练预算下不仅恢复且超越 BF16 微调精度，实现 3.9 倍吞吐量加速，为高效部署提供可行路径。

## 2. 方法论

### 核心思想
基于量化误差主要影响低熵 token 的发现，ReQAT 从三个层面专门强化低熵 token 的预测质量：重新对齐推理轨迹、选择性压低低熵位置熵值、以及量化友好的 KV 缓存初始化。

### 关键技术细节

#### (i) Trace-Aligned QAT (TAQ)
- **两阶段流程**：Stage-1 在 BF16 下对完整数据集 `D_FT` 进行微调，获得全精度检查点；Stage-2 在**相同推理轨迹**的子集 `D_TAQ ⊆ D_FT` 上进行 QAT（固定 70M token）。
- **动机**：两次对齐的轨迹确保 QAT 更新反复作用于同一低熵 token 位置，从而集中学习信号纠正量化敏感点。实验表明，若 QAT 使用不同轨迹则收益甚微。

#### (ii) Selective Entropy Minimization (SEM)
- **辅助损失**：在标准负对数似然 `L_SFT` 基础上增加熵最小化项：
  ```
  L_SEM = L_SFT + λ · (1/T) ∑_t w_t H_t
  ```
  其中 `H_t` 为 token t 的预测熵，`w_t` 为软权重，仅对低熵 token 施加较大权重。
- **权重设计**：
  ```
  w_t = max(0, 1 - (H_t - H_min) / (τ - H_min + ε))
  ```
  τ 设为批次内第 75 百分位熵值，确保仅对低于该阈值的 token 进行增强。
- **差异**：不同于以往全局熵正则化，SEM 仅选择性作用于低熵位置。

#### (iii) Q-FIT (Quantization-Friendly Initialization)
- **目的**：减少 KV 缓存量化（W4A4KV4）引入的额外误差，提升 QAT 稳定性。
- **方法**：联合校准**预 RoPE 通道缩放**和**后 RoPE 通道偏移**：
  ```
  ˜Q = R(Qpre ⊙ s),   ˜K = R(Kpre ⊘ s) - m
  ```
  其中 s 为配对通道缩放因子（由单标量 α_s 控制幅度），m 为后 RoPE 偏移（由 α_m 控制幅度）。
- **校准**：通过网格搜索 (α_s, α_m) 最小化 BF16 与 KV4 注意力输出之间的 MSE。每层独立选择最优组合，适应不同层 KV 缓存分布特性。
- **实现**：缩放因子 s 可融合进投影权重，无推理开销；偏移 m 在推理时作为减法加入。

### 算法流程（文字说明）
1. 从预训练 LRM 开始，在 BF16 下使用完整数据集 `D_FT` 微调（Stage-1）。
2. （可选）运行 Q-FIT：在少量校准数据（WikiText-2）上计算预 RoPE 配对缩放因子和后 RoPE 偏移，选取使注意力输出误差最小的参数 α_s、α_m。
3. 构建子集 `D_TAQ ⊆ D_FT`（与 Stage-1 所用轨迹同源）。
4. 在 FP4 模拟环境下，对模型进行 Trace-Aligned QAT，优化目标为 `L_SEM`（包含 SEM 损失），处理 D_TAQ 中的推理轨迹。训练参数：学习率 1e-5，AdamW，余弦学习率调度，有效 batch size 2，最大序列长度 25K。
5. 输出最终 FP4 模型，用于 W4A4KV4 部署。

## 6. 主要结论与发现

1. **FP4 量化失败根源**：低熵 token 是主要瓶颈。量化噪声增加非 top-1 token 的采样概率，导致符号错误级联。
2. **ReQAT 恢复并超越全精度**：在 NVFP4 W4A4KV4 下，ReQAT 达到 **65.94% AIME 精度**，超过 BF16 baseline（56.83%）和 BF16 Full-FT（65.46%），且不增加训练预算。
3. **各组件贡献**：TAQ 提供基础恢复（沿相同轨迹更新），Q-FIT 稳定 KV 缓存量化，SEM 进一步锐化低熵置信度。三者叠加效果最优。
4. **吞吐量提升**：ReQAT 在 DGX Spark 实现 **3.9×** 速度提升，在 B200 实现 **3.1×**（考虑 Q-FIT 微小开销约 4-5%）。
5. **泛化能力**：在代码生成（LiveCodeBench）上，ReQAT 也匹配或略超 BF16 Full-FT 精度。在非推理任务（MMLU）上保持与基线相当。
6. **机制分析**：TAQ 通过重新分配梯度贡献（低熵 token 梯度占比增加）优化量化敏感位置，而非简单靠更多训练数据。

## 7. 优点

- **问题发现新颖**：首次将 LRM 量化失败归因于低熵 token，并通过混合精度解码和噪声注入实验佐证。
- **方法简洁有效**：TAQ 仅在相同轨迹上复用 QAT 即可大幅提升，无需额外数据；SEM 用软权重温和控制熵；Q-FIT 联合校准两种变换，适应性强且无推理开销。
- **实验严谨**：控制训练预算一致，报告多次种子平均结果；提供详细的消融和机制分析；在真实硬件上进行吞吐量测量。
- **实用性**：完全兼容已有的 FP4 硬件路径（NVFP4），仅增加极小的校准开销，实际部署可行。

## 8. 不足与局限

- **依赖 SFT 数据质量**：TAQ 建立在 SFT 数据集之上，若推理轨迹本身噪声大或弱，则收益有限。论文指出该限制。
- **模型覆盖有限**：主要测试 DeepSeek-R1 蒸馏模型，其他 LRM（如 o1、QwQ）尚未验证。且仅对 14B 和 8B 规模实验，更大模型（如 70B）仅在图1(a)中展示 PTQ 退化，但未提供 ReQAT 结果。

- **吞吐量测量细节**：DGX Spark 不支持原生 NVFP4 KV cache，使用了 W4A4KV8 替代，可能影响加速比泛化性。
- **未见强化学习（RL）集成**：论文指出 TAQ 可与知识蒸馏结合，但当前仅基于 SFT。未来工作可探索在 RL 中的适用性。
- **基准偏差**：AIME 精度提高明显，但 GSM8K/MATH-500 上增益较小，且在 MMLU 上未见改善，说明方法在简单推理或通用知识上优势有限。
