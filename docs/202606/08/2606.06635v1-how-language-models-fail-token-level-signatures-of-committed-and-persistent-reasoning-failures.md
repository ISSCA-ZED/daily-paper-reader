## 摘要
语言模型推理的失败通过各种不同的过程显现，这些过程在推理轨迹中留下了可识别的特征。我们利用词元级的不确定性信号对这些失败进行刻画，发现它们源于两种经验上可区分的流程。第一种是承诺性失败，其中模型在推理轨迹早期就锁定了一条错误的推理路径。一个关键的诊断特征是承诺点，超过该点后，考虑额外的词元反而会阻碍失败检测，而非促进。第二种是持续性不确定性，不确定性在整个过程中不断累积，需要完整的轨迹才能最好地区分失败与成功完成。这些特征在23个模型-数据集配置中复现，该框架的可证伪预测在23个案例中的20个中成立，两种失败模式的表现均远超随机水平。最后，我们展示了失败模式框架对自一致性有直接影响，能识别何时不确定性信号对其有补充作用，以及何时可以选择性地跳过自一致性。这些结果为理解何时LLM推理失败变得可检测以及如何相应调整检测策略提供了基础。

## Abstract
Failures in language model reasoning emerge through distinct processes that leave identifiable signatures in the reasoning trace. We characterize these failures using token-level uncertainty signals, finding they arise through two empirically distinguishable processes. The first is committed failure, in which a model locks onto an incorrect reasoning path early in its trace. A central diagnostic signature is the commitment point, beyond which considering additional tokens hurt rather than help failure detection. In the second, persistent uncertainty, uncertainty instead accumulates throughout, and the full trace is needed to best distinguish failing from successful completions. These signatures reproduce across 23 model-dataset configurations, with the framework's falsifiable predictions holding in 20 of 23 cases, well above chance across both failure modes. Finally, we demonstrate our failure mode framework has direct implications for self-consistency, identifying when uncertainty signals complement it and when it can be selectively skipped. These results offer a foundation for understanding when LLM reasoning failures become detectable and for adapting detection strategies accordingly.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题**：LLM在复杂推理任务中的失败检测是重要挑战。现有方法（如自一致性、不确定性量化）将失败视为二元分类，但未区分失败产生过程的差异性。模型可能因早期锁定错误路径而固定输出错误答案（自一致性无法检测），也可能因持续摇摆而需要聚合多步输出。因此，统一检测策略无法在所有情况下最优。
- **整体含义**：通过刻画失败的产生过程，而非仅关注结果，可构建适应性检测方法，提升部署可靠性。本研究利用仅需输出词元log概率的不确定性信号，从单次推理轨迹中诊断失败模式。

## 2. 方法论

### 核心思想
- 将LLM推理失败分为两种模式：**承诺性失败**（comitted failure）和**持续性不确定性**（persistent uncertainty），分别对应不同的不确定性态势。
- 引入**承诺点**（commitment point）概念：推理轨迹中不确定性信号对失败预测最有效的词元位置，超过该点后新增词元反而降低检测性能。

### 关键技术细节
1. **不确定性特征**：从每个词元位置提取五种信号：
   - 熵（top-K分布的分散度）
   - 边际（top-2概率差）
   - 负对数似然（top token的置信度）
   - 核（达到概率阈值0.9所需词元数）
   - 近平局（与top token概率差距在10%内的词元比例）
   对每个前缀窗口（如128,256,…,2048词元）计算均值和最大值，共10个特征。
2. **分类方法**：使用逻辑回归（5折交叉验证，带平衡类权重）基于上述特征预测失败，以PR-AUC为评估指标。
3. **承诺点识别**：在PR-AUC随前缀窗口大小变化的曲线上，若呈现倒U形（峰值处PR-AUC显著高于全轨迹基线），则为承诺性失败；若PR-AUC单调上升且全轨迹最优，则为持续性不确定性。
4. **前最终分析（pre-final analysis）**：剔除答案标记后的词元，消除轨迹长度混淆。

- **对比方法**：未显式对比其他方法，但评估了自一致性（self-consistency）策略的互补性。核心实验是框架自身的分类验证。

### 评估协议
- 每条推理轨迹一个样本，temperature=0.6。
- 使用5折逻辑回归的越折叠预测计算PR-AUC，通过自举法（10,000次重采样）评估统计显著性。

## 6. 主要结论与发现

1. **两种失败模式经验可区分**：承诺性失败在14/14配置中均显示ΔPR-AUC>0，符号检验p=6.1×10⁻⁵；持续性不确定性在6/9配置中符合负Δ预测，其余边界情形接近零。
2. **框架可证伪预测成立**：23个配置中20个符合方向预测，p=2.4×10⁻⁴。
3. **承诺点存在性验证**：承诺性失败中早于全轨迹窗口达到峰值，超过后性能下降；持续性不确定性中全轨迹始终最优。
4. **自一致性优化**：承诺性失败下，前-最终特征的早期窗口可实现高达30%跳过率而不损失召回率；不确定性信号可与自一致性互补，三个配置中联合PR-AUC均高于单独使用。

## 7. 优点

- **方法轻量**：仅需词元级log概率，无需模型内部表示，适用于闭源API模型（如GPT-4o、Gemini）。

- **实验验证充分**：多模型、多数据集、多统计检验，结果稳定且重复。
- **考虑关键混淆因素**：前最终分析消除轨迹长度偏差，增强了结论可靠性。

## 8. 不足与局限

- **适用性限制**：失败率需在15%-60%范围内，且AUROC>0.55；极端失败率下无法可靠检测。
