## 摘要
自蒸馏通过将参考答案重写为更匹配模型自身分布的训练数据来提高学习效率。然而，参考答案也引入了强烈的风格偏差，导致生成模型模仿表面形式而非学习有用的推理模式。我们观察到重写数据中包含大量高困惑度（PPL）令牌，这些令牌来自两个不同来源：有益的知识增强逻辑校正，以及由参考模仿引起的有害风格漂移。平等对待所有此类令牌可能会破坏基础模型的原始分布并降低性能，尤其是在困难推理任务上。为了解决这个问题，我们提出了分布对齐自蒸馏（DASD），它使用答案感知参考模型生成候选令牌，并根据基础模型的置信度动态过滤这些令牌。DASD保留编码有用逻辑知识的令牌，同时抑制分布不对齐的风格噪声。在数学、代码和常识推理基准上的实验表明，DASD始终优于竞争基线，减少了高PPL令牌的数量，并提高了跨不同难度任务的鲁棒性。

## Abstract
Self-distillation improves learning efficiency by rewriting reference answers as training data that better matches the model's own distribution. However, reference answers also introduce strong stylistic biases, causing the generative model to imitate surface forms rather than learn useful reasoning patterns. We observe that the rewriting data contains a large number of high-perplexity (PPL) tokens, coming from two distinct sources: beneficial knowledge-enhancing logical corrections, and harmful stylistic drift induced by reference imitation. Treating all such tokens equally can disrupt the base model's original distribution and degrade performance, especially on difficult reasoning tasks. To address this, we propose Distribution-Aligned Self-Distillation (DASD), which uses an answer-aware reference model to generate candidate tokens and dynamically filters them according to the base model's confidence. DASD preserves tokens that encode useful logical knowledge while suppressing distributionally misaligned style noise. Experiments on math, code, and commonsense reasoning benchmarks show that DASD consistently outperforms competitive baselines, reduces high-PPL tokens, and improves robustness across tasks of varying difficulty.

## 1. 核心问题与整体含义（研究动机和背景）
- **研究动机**：自蒸馏（Self-distillation）通过将参考答案（reference answers）重写为训练数据，提升大语言模型（LLM）在下游任务上的学习效率。但参考答案会引入强烈的风格偏差，导致模型模仿表面形式（如模板、表达习惯）而非学习真正的推理模式。
- **核心问题**：自蒸馏产生的重写数据中包含大量**高困惑度（high-PPL）令牌**，这些令牌来自两种截然不同的来源：
  - **有益的逻辑校正**：基础模型本身不擅长但解决题目必需的推理步骤。
  - **有害的风格漂移**：从参考答案继承的冗余表达、推理模板等无用噪声。
- **现有方法局限**：传统自蒸馏对所有令牌一视同仁优化，无法区分有用逻辑修正与有害风格噪声。已有的令牌选择方法（如Mask-PPL、ProFit）简单丢弃所有高PPL令牌，会同时丢弃有益的推理修正；Hint-Decoding方法融合双模型分布，但受参考答案过度自信影响，仍偏向参考答案。
- **论文目标**：提出一种动态令牌选择机制，在保留有益逻辑修正的同时抑制分布不对齐的风格噪声，提升自蒸馏在困难推理任务上的鲁棒性和效果。

## 2. 方法论：核心思想、关键技术细节与算法流程
- **核心思想**：构建**分布对齐的自蒸馏（DASD）** 框架，利用一个**答案感知的参考模型**生成候选令牌池，然后基于**基础模型的局部置信度**动态筛选令牌。高置信度的候选令牌（即基础模型熟悉的令牌）被优先保留；当所有候选令牌置信度都低于阈值时，强制采用参考模型的最优令牌，以保证推理正确性。
- **关键技术细节**：
  - **参考模型**：与基础模型相同，但以标准答案作为额外条件，生成高质量推理路径。在每个时间步，从参考模型输出分布中取 top-K 个候选令牌。
  - **动态选择策略**：
    1. **分布对齐优先**：按概率降序遍历候选令牌，选择第一个满足基础模型条件概率 > 阈值 τ 的令牌。
    2. **知识回退机制**：若所有 K 个候选均未通过置信度检查，则直接选择参考模型贪心解码的第一个令牌（c₁），以保证逻辑连续性。
  - **训练阶段**：仅保留生成结果与标准答案一致的样本，构成对齐数据集，用标准因果语言建模损失微调基础模型。
- **算法流程（文字描述）**：
  1. 对于每个训练样本 (x, y*)，初始化空序列 y。
  2. 循环直到生成 EOS 令牌或达到最大长度：
     a. 参考模型根据 x, y 前缀和 y* 计算 top-K 候选令牌 C。
     b. 依次计算每个候选令牌在基础模型下的概率 p = Pθ(ci|x, y)。
     c. 选出第一个 p > τ 的令牌；若无，则取 c₁。
     d. 将选中的令牌追加到 y。
  3. 收集所有正确生成的样本，构成对齐数据集 D_aligned。
  4. 在 D_aligned 上优化基础模型 Mθ。

## 6. 主要结论与发现
- DASD 在所有三个基准、三个基座模型上均持续优于传统自蒸馏和对比方法，尤其在困难推理任务（如 MATH 高难度级别）上提升显著。

- 消融实验表明：
  - 置信度阈值 τ=0.20 达到最佳平衡；过高或过低均损害性能。
  - 候选令牌数 K=6 最优；K=3 过于限制参考知识注入，K=9 则参考引导不足。
  - 硬令牌回退采用参考模型最优令牌（ref-mode）优于从基础模型选最自信令牌（base-mode），说明保留逻辑正确性更重要。
- 令牌分布分析显示：92.54% 的令牌为双模型一致令牌；过滤令牌中基础模型选中的占主导，但随难度升高，强制使用参考令牌的比例增加，说明 DASD 自适应调节。

## 7. 优点
- **方法创新性**：首次区分自蒸馏数据中高 PPL 令牌的两种来源（有益逻辑修正 vs 有害风格漂移），并设计基于置信度的动态过滤，思路清晰且实用。
- **分布式对齐思想**：不是简单丢弃或直接替换，而是通过候选池和阈值机制在保留基础模型习惯的同时吸收参考模型的正确知识。
- **实验充分**：包含多模型、多任务、多难度、消融、机制分析，验证了方法鲁棒性和可迁移性。
- **开源友好**：论文提供匿名代码仓库（https://anonymous.4open.science/r/emnlp-SD-6AB2），有利于复现。
