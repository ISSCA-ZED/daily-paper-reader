## 摘要
指令调优的语言模型在面对相同的因果推理问题时，如果将其英文变量名替换为保持类型的占位符，可能会给出不同的答案，尽管结构因果模型和正确答案保持不变。我们探究这种词汇间隙是否反映了占位符视图下的信息丢失，或者是从一个仍携带答案相关内容的表征中读出了错位的结果。Vernier采用配对视图权重更新作为工具，然后检查间隙闭合后留下的机制。在有效工作区间内，证据支持表征错位的解释。变量名探针在占位符视图上变得更加准确，对Qwen-7B、Qwen-14B和Llama-3.1-8B的激活修补表明，决策令牌表征可以在视图之间传递答案身份。重新对齐视图的更新是对原始提示和占位符提示的反事实增强，而答案子空间KL主要增强了中间答案信念的一致性。成功受限于模型家族、规模和任务。CRASS迁移在Qwen各规模和Llama上可靠，e-CARE仍然较弱，初步的非因果重命名任务显示出类似的定性模式。

## Abstract
Instruction-tuned language models can answer the same causal-reasoning question differently after its English variable names are replaced by type-preserving placeholders, although the structural causal model and the gold answer are unchanged. We ask whether this lexical gap reflects information loss in the placeholder view or a misaligned read-out from a representation that still carries answer-relevant content. Vernier uses a paired-view weight update as an instrument and then inspects the mechanism left after the gap closes. In the working regimes, the evidence favours representational misalignment. A variable-name probe becomes more accurate on the placeholder view, and activation patching on Qwen-7B, Qwen-14B, and Llama-3.1-8B shows that the decision-token representation can transfer answer identity between views. The update that realigns the views is counterfactual augmentation over original and placeholder prompts, while the answer-subspace KL mainly sharpens intermediate answer-belief agreement. Success is bounded by model family, scale, and task. CRASS transfer is reliable across Qwen scales and Llama, e-CARE remains weak, and preliminary non-causal rename tasks show a similar qualitative pattern.

# 论文总结：Vernier: Probing Representational Misalignment Behind Lexical Gaps in Causal Reasoning

## 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：指令微调的语言模型在因果推理任务中，当将变量名（如“smoking”）替换为类型保持的占位符（如“X1”）后，可能给出不同答案，尽管结构因果模型、联合分布、查询和标准答案均未改变。这一“词汇间隙”（lexical gap）现象在多个模型家族中普遍存在。
- **核心问题**：该间隙的原因是什么？存在两种竞争性解释：
  - **信息缺失假说（information deficit）**：占位符视图丢失了故事层面的内容，模型无法回答。
  - **表征错位假说（representational misalignment）**：内容仍然存在于表征中，但模型从不同的词汇形式读取时存在错位。
- **整体含义**：两种解释对应不同的修复策略。Vernier 通过设计可控的权重更新作为工具，探究间隙闭合时内部机制的变化，从而区分两种假说。

## 2. 方法论

### 核心思想
- 使用 LoRA（Low-Rank Adaptation）在原始提示 q 和结构保持的扰动提示 T(q)（变量名替换为占位符）组成的成对视图上训练。
- 训练目标结合任务损失（每个视图都有答案监督）和答案子空间对称 KL 散度，强制两个视图的答案分布一致。
- 利用更新后的模型作为“仪器”，通过探针、激活修补、推理时映射等机制分析来揭示间隙消失背后的本质。

### 关键技术细节
- **结构保持扰动 T**：将因果问题中的变量名及其变体统一替换为 X1, X2, …，保持因果图、查询、答案集和正确答案不变。
- **Vernier 损失函数**：  
  L = α [L_task(P0) + L_task(P1)] + β L_cons(P0, P1)  
  L_cons = 1/2 KL(p^Y_P0 ∥ p^Y_P1) + 1/2 KL(p^Y_P1 ∥ p^Y_P0)  
  其中 p^Y 为限制在答案令牌子集（如 yes/no）上的 softmax 分布。α=β=1。
- **LoRA 配置**：秩 r=16，alpha=32，dropout=0.05，应用于所有注意力层的 query, key, value, output 投影。
- **优化器**：AdamW，学习率 1e-4，线性预热 50 步，余弦退火，总步数 500，batch size 4（成对）。

### 算法流程（文字说明）
1. 输入：基础 LM（冻结权重）、LoRA 适配器 φ、答案令牌集合 Y、批数据 {(q_i, T(q_i), y*_i)}。
2. 分别对原始和扰动提示进行分词，得到 P0 和 P1。
3. 前向传播得到第一个生成位置的 logits，经 softmax 得到答案分布 p^(0) 和 p^(1)。
4. 计算任务损失 L_task = -1/B ∑[log p^(0)_i,y*_i + log p^(1)_i,y*_i]。
5. 计算一致性损失 L_cons = 1/(2B) ∑[KL(p^(0)_i ∥ p^(1)_i) + KL(p^(1)_i ∥ p^(0)_i)]。
6. 仅更新 LoRA 参数 φ，优化目标 αL_task + βL_cons。

## 3. 实验设计

### 使用的数据集与场景
- **In-distribution (ID)**：CLadder（commonsensical 子集），训练集 0-1499，测试集 1500-1699（n=200），另使用更大 n=1000 的切片。
- **Out-of-distribution (OOD)**：
  - CRASS（n=200，全部 274 个用于扩展）
  - e-CARE（n=200，n=1000 用于扩展）
- **能力评估**：MMLU、HellaSwag、GSM8K（各 n=200）
- **非因果任务**：BBH 中的 logical deduction 和 reasoning about colored objects（对象名替换为占位符），n=100 和 n=20。

### Benchmark 与对比方法
- **Baseline**：Base（无微调）、P0-only SFT（仅原始提示）、R-Drop（两个 dropout 采样视图的一致性）、Twin task（β=0，无 KL）、Full-vocabulary KL（全词汇 KL）。
- **指标**：主要指标为词汇间隙 Gap = P0 - P1（百分比点），同时报告 P0 和 P1 准确率以区分闭合是来自 P1 提升还是 P0 退化。

### 实验数量与充分性
- **模型覆盖**：9 个模型跨越 5 个家族（Phi-3-mini 3.8B, Qwen2.5 1.5B/3B/7B/14B/32B, Llama-3.1-8B, Mistral-7B, Gemma-2-2B）。
- **消融实验**：损失组件消融（β 权重、KL vs MSE、LoRA 秩）、训练数据消融（CLadder 仅训练 vs 联合 CLadder+CRASS+e-CARE）、占位符方案压力测试、能力变化评估。
- **机制诊断**：余弦相似度、logit-lens 分歧、线性探针、激活修补（匹配/随机/不同预测供体控制）、推理时线性/MLP 映射。
- **统计验证**：某些实验使用三种子平均±标准差，后验使用配对自助法 95% 置信区间。

**充分性评价**：实验设计系统全面，覆盖行为、机制、能力、边界条件四个维度，消融和对照充分，能够区分不同假说。但部分 OOD 数据集采样较小（如 colored objects 仅 20 项），能力评估仅 200 项，可能不足以全面反映变化。

## 5. 主要结论与发现

1. **词汇间隙源于表征错位而非信息丢失**：在有效工作区间（Qwen-7B/14B/32B, Llama-3.1-8B），Vernier 闭合间隙并且 P1 和 P0 准确率同时提升；探针分析显示占位符视图中变量名表征的可恢复性反而上升；激活修补证明决策令牌表征可以因果地传递答案身份（P1 补丁后 97%~99.5% 的项目与 P0 一致）。
2. **行为引擎是成对反事实增强（双视图任务损失）**：β=0 的 Twin task 已能闭合大部分 ID 间隙并取得相似 OOD 改进，答案子空间 KL 主要精炼中间信念一致性（logit-lens 分歧减半），不驱动核心行为。
3. **推理时单方向映射无法闭合间隙**：线性/MLP 映射在所有模型上失效，说明错位是子路特有的、条件依赖的，与情感、真实性等可被单一方向控制的行为属性不同。
4. **成功受限于模型规模、家族和任务**：
   - Qwen 容量阈值在 1.5B~3B 之间，3B 成功而 1.5B 失败；Phi-3 和 Gemma 失效模式为 P0 退化或机制诊断无变化。
   - CRASS 迁移可靠（Qwen 7B 降 27%，14B 降 27%），e-CARE 迁移弱（仅 7B 有显著下降）且随规模非单调。
   - 非因果重命名任务中也观察到类似定性模式，但可被部分推理时映射修复，与因果任务不同。
5. **能力退化**：Mistral-7B 在默认学习率下 GSM8K 下降 36.5 个百分点，需要特殊 rescue 方案；其他模型在 200 项采样中未检测到广泛退化。

## 6. 优点

- **将鲁棒性问题转化为可证伪的机制问题**：提出信息缺失与表征错位两种对立假说，并设计多个独立的诊断测试（探针、激活修补、映射等）进行区分，不依赖单一的基准数字。
- **控制良好的实验设计**：Vernier 仅作为干预工具，不宣称是通用的微调方法；通过配对视图 + 答案子空间 KL 有针对性地测试特定假说。
- **系统的边界刻画**：通过家族内规模扫描、多模型比较、压力测试等明确标定方法有效和失效的条件。
- **因果分析手段丰富**：使用激活修补、供体控制、随机基线等，增强了机制结论的可靠性。
- **坦诚报告失败模式**：明确列出 Phi-3、Mistral 的失效及 Mistral 的能力退化，使结论更可信。

## 7. 不足与局限

- **实验覆盖有限**：
  - 多数 OOD 和能力评估使用 n=200，统计功效较低；colored objects 仅 20 项。
  - 最大模型到 32B（QLoRA），未验证更大模型（如 70B 以上）的适用性。
  - 能力评估仅三个基准（MMLU, HellaSwag, GSM8K），未覆盖更全面的能力集。
- **e-CARE 迁移弱且原因不明**：即便在表征对齐提升的情况下，e-CARE 间隙缩小有限，暗示可能存在其他因素（如任务格式差异），本文未深入解释。
- **非因果任务分析初步**：仅两个 BBH 子任务，且 colored objects 样本量极小，结论不能泛化。
