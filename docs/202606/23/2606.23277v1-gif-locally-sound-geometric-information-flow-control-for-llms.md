## 摘要
大型语言模型越来越多地协调智能体系统中敏感数据、不可信输入与特权操作之间的交互，从而带来安全与隐私风险。这些风险包括操纵下游工具使用的提示注入，以及通过模型输出泄露机密信息。最近基于信息流控制（IFC）的防御方法显示出潜力，但缺乏用于推理模型自身信息流的原则性语义基础。由于在自回归LLM中，任何输入标记都可能影响任何输出标记，现有方法面临严重的污点爆炸问题。我们提出几何信息流（GIF），这是一个从输入标记到输出追踪信息流的语义框架。GIF利用LLM雅可比矩阵和局部输出几何，来界定扰动输入跨度与模型输出之间的香农互信息上限，从而通过自动微分和低秩近似在大型模型上获得可扩展的度量。与基于注意力或相关性的归因启发式方法不同，GIF满足局部几何可靠性，并且我们提供了一个完全机械化的Lean 4证明，证明在局部正则性假设下，它界定了由给定提示引起的真实信息流的上限。我们在多个提示注入和隐私泄露基准测试中，针对完整性和机密性任务评估了GIF。即使没有下游解分类器，GIF也实现了近乎完美的召回率，优于基于注意力的基线方法。结合轻量级基于LLM的解分类器，它匹配或超过了直接使用LLM作为评判器的基线方法（如GPT-5.5高推理）的F1分数，同时使用的token成本降低了高达81倍。使用小型替代模型检测到的GIF流可以迁移到更大的最先进模型和其他模型家族，即使替代模型小至200倍，这表明无需梯度访问即可进行黑盒部署。

## Abstract
Large language models increasingly mediate interactions between sensitive data, untrusted inputs, and privileged actions in agentic systems, creating security and privacy risks. These range from prompt injections that manipulate downstream tool use to leakage of confidential information through model outputs. Recent Information Flow Control (IFC)-based defenses show promise but lack a principled semantic foundation for reasoning about information flow through the model itself. Since any input token may influence any output token in an autoregressive LLM, existing approaches suffer from severe taint explosion.   We present Geometric Information Flow (GIF), a semantic framework for tracking information flow from input tokens to outputs. GIF uses the LLM Jacobian and local output geometry to upper-bound the Shannon mutual information between perturbed input spans and model outputs, yielding a scalable measure computable on large models via automatic differentiation and low-rank approximation. Unlike attention-based or correlational attribution heuristics, GIF satisfies local geometric soundness, and we provide a fully mechanized Lean 4 proof that it upper-bounds the true information flow induced by a given prompt under local regularity assumptions.   We evaluate GIF on integrity and confidentiality tasks across multiple prompt-injection and privacy-leakage benchmarks. GIF achieves near-perfect recall even without a downstream declassifier, outperforming attention-based baselines. Combined with lightweight LLM-based declassifiers, it matches or exceeds the F1 of direct LLM-as-judge baselines such as GPT-5.5 xhigh reasoning while using up to 81x lower token cost. GIF flows detected with small surrogate models transfer to larger state-of-the-art models and other model families, even when the surrogate is up to 200x smaller, suggesting black-box deployment without gradient access.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：大型语言模型（LLM）在智能体系统中协调敏感数据、不可信输入与特权操作，导致两大安全风险——**提示注入**（攻击者控制内容成为指令，影响下游工具调用等特权操作）和**隐私泄露**（机密信息通过模型输出泄露）。
- **现有方法局限**：基于信息流控制（IFC）的防御（如 RTBAS）缺乏原则性语义基础，采用粗粒度的“可信/不可信”标签，在自回归 LLM 中任何 token 都可能影响任何输出 token，导致**严重的污点爆炸**（overtaint），几乎阻塞所有后文；而启发式方法（如注意力、梯度归因）缺乏定量信息流语义。
- **研究目标**：提出一种**定量、可计算、局部可靠**的信息流追踪框架，原则性地测量输入跨度（span）对输出的影响，从而为策略强制执行或解分类提供依据。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- **几何信息流（GIF）**：将信息流建模为**局部通道**——固定一个基础提示 \(x\)，将一个连续 token 跨度 \(T\) 的嵌入用高斯噪声扰动，测量扰动后下一个 token 分布与原始分布之间的**香农互信息** \(I(U_T; Y)\)。
- 由于精确互信息不可计算，用**局部高斯替代通道**来近似：通道输出为 \(Y_T = A_T(x) U_T + N\)，其中 \(A_T(x) = F_{\text{sm}}(p(x))^{1/2} W J_T(x)\)，\(J_T(x)\) 是跨度到隐藏状态的雅可比矩阵，\(F_{\text{sm}}\) 是 softmax 分布的 Fisher 信息矩阵。该替代通道的容量（mutual information）即为 **GIF 分数**：\(\text{Cap}_T(\tau; x) = \frac{1}{2} \log \det(I + \tau M_T(x))\)，其中 \(M_T(x) = J_T^\top W^\top F_{\text{sm}} W J_T\)。
- 用**影响**（Influence）作为更便宜的代理：\(\text{Inf}_T(x) = \operatorname{tr} M_T(x)\)，且容量 \(\leq \frac{\tau}{2}\text{Inf}_T(x)\)，局部一阶一致。

### 关键技术细节
- **局部可靠性**（Locally Sound）：证明在局部正则性假设下，GIF 分数是真实互信息的**上界**，至多相差 \(o(\tau)\)。该证明已在 **Lean 4** 中完全机械化（形式化验真）。
- **高效估计**：避免显式构建雅可比矩阵，采用 **Hutch++ 随机迹估计**，通过向量-雅可比乘积（VJP）和低秩近似计算 \(\text{Inf}_T(x)\)，只需少量随机探测（probe）。理论保证：对任意 \(\varepsilon, \delta \in (0,1)\)，用 \(\ell \geq 2 + 4/(\varepsilon\sqrt{\delta})\) 次 oracle 查询可得到 \((1\pm\varepsilon)\) 相对误差估计，概率至少 \(1-\delta\)。
- **系统实现**：包括标签组件（按安全策略标记 token）、流追踪组件（为每个生成的敏感 token 计算 GIF 分数）、解分类器（基于阈值或轻量级 LLM 判断）。

## 7. 优点

- **原则性语义基础**：首次将 Jacobian 几何转化为**定量信息流控制语义**，并给出形式化局部可靠性证明（Lean 4 机械化），与启发式方法有本质区别。
- **可扩展性**：通过随机迹估计避免显式构建 Jacobian，适用于当代大规模 LLM。
- **实用性**：支持白盒（需模型内部）和黑盒（通过替代模型迁移）部署，显著降低计算和 token 成本。
- **强实验**：跨多模型、多基准、多指标全面验证，包括跨家族/规模迁移，结果稳健。
- **轻量解分类器设计**：仅需少量 top 流 token 即可达到甚至超越完整 LLM 判断。

## 8. 不足与局限

- **局部性假设**：理论保证仅在小扰动下成立（o(τ) 上界），若真实输入变化大（如大跨度重写），局部线性近似可能失效。
- **需要模型内部**：除非使用替代模型（需验证迁移性），否则需访问原始模型的梯度（白盒要求），限制了对完全闭源模型的应用。
- **标签依赖启发式**：安全标签分配基于简单规则（如低/高），更复杂的策略（如多级、去中心化策略）未探索。
- **未检验对抗性鲁棒性**：论文未讨论攻击者能否刻意构造输入以绕过 GIF 检测（例如制造虚假低流）。
- **基准多样性有限**：仅涉及三类智能体场景（工具调用、浏览器任务、MCP），其他场景（多 agent 交互、记忆长期积累）未覆盖。
- **计算成本细节缺失**：实际推理时间、GPU 小时数、Hutch++ 额外开销未报告，仅推算 token 成本。
- **公共性**：虽然 Lean 4 证明公开，但 GIF 实现代码是否完全开源未明确说明（仅提 proof 仓库）。
