## 摘要
大语言模型（LLM）在数学推理中达到了高准确率，但在同一问题上的单个轨迹存在分歧；有些得到正确答案，而另一些则失败。先前的研究在步骤、片段或句子层面分析失败，或针对已经发生失败的 token 进行分析。这些方法均未能识别出触发向失败转变的具体 token。我们引入了悬崖 token（cliff token），即基于单侧双比例 z 检验，在随局部 token 潜力缩放的自适应阈值下，其 token 级潜力显著下降的 token。在七个模型和三个数学推理基准（GSM1K、MATH500、AIME 2025）上，悬崖 token 充当失败触发点；删除第一个悬崖 token 并重新采样可将 pass@64 恢复至 1.0，而保留它则仅限于将恢复率限制在 0.71 到 1.00 之间。我们进一步引入了一个悬崖分类法，包括确定性悬崖、不确定性悬崖和采样偏移悬崖，由贪婪选择和 token 熵定义。每种类型都具有不同的概率特征，并且该分类法可跨模型规模泛化。最后，我们通过在悬崖位置进行单 token 偏好优化（Cliff-DPO）验证了该分类法。在 GSM8K 上训练后，Cliff-DPO 在多个基准上的准确率提升高达 6.6 个百分点。在不确定性和采样偏移悬崖上进行优化可改进推理，而确定性悬崖则不然。

## Abstract
Large language models (LLMs) reach high accuracy in mathematical reasoning, but individual traces on the same problem diverge; some arrive at the correct answer while others fail. Prior work analyzes failure at the step, chunk, or sentence level, or at tokens where failure has already occurred. Neither identifies the precise token that triggers the shift toward failure. We introduce the cliff token, a token where the token-wise potential drops significantly under an adaptive threshold that scales with the local token-wise potential, based on a one-sided two-proportion z-test. Across seven models and three mathematical reasoning benchmarks (GSM1K, MATH500, AIME 2025), cliff tokens act as failure triggers; deleting the first cliff token and resampling recovers pass@64 to 1.0, while keeping it limits recovery to between 0.71 and 1.00. We further introduce a cliff taxonomy of deterministic, uncertain, and sampled-off cliffs, defined by greedy choice and token entropy. Each type has distinct probabilistic characteristics, and the taxonomy generalizes across model scales. Finally, we validate the taxonomy via single-token preference optimization at cliff positions (Cliff-DPO). Trained on GSM8K, Cliff-DPO improves accuracy across benchmarks by up to +6.6. Optimizing at uncertain and sampled-off cliffs improves reasoning, while deterministic cliffs do not.

# 论文核心总结：Cliff Tokens

## 1. 核心问题与整体含义（研究动机和背景）
- **问题**：大语言模型（LLM）在数学推理中，即使整体准确率较高，**同一问题下不同推理轨迹的结果却存在分歧**：部分轨迹正确，部分错误。现有失败分析大多关注宏观层面的步骤、片段或句子，或仅分析**失败已经发生之后**的 token，未能精确定位**触发失败转向的起始 token**。
- **意义**：理解“推理何时以及为何会偏离正确路径”对诊断和改善 LLM 推理能力至关重要；单 token 级别的失败触发点识别可为更高效的偏好优化提供目标信号。

## 2. 方法论
### 2.1 核心思想
- **Cliff Token（悬崖 token）**：在推理轨迹中，某个 token 位置处“到达正确答案的概率”（称为 **token-wise potential**）发生统计显著且大幅下降，该 token 即为失败触发点。
- 引入**自适应阈值**（基于单侧双比例 z 检验），区分真实下降与采样噪声，避免固定阈值在方差较大区域产生误报。

### 2.2 关键技术细节
- **Token-wise potential**：给定前缀 \(c_{\le t}\)，估计从该位置继续生成直到得到正确答案的概率（通过 N=64 次 rollout 采样计算成功率）。
- **悬崖 token 判定条件**：  
  \[
  \Delta_t = \text{pot}_{t-1} - \text{pot}_t > 0.1 + 1.645 \times SE_t
  \]  
  其中 \(SE_t\) 为前后两个潜在估计的标准误差。
- **早期终止启发式**：若连续20个 token 的 potential 为0，则判定轨迹不可恢复，停止后续 rollout，降低计算成本。

### 2.3 悬崖分类（Cliff Taxonomy）
基于**贪婪选择**（Greedy）和**token熵**（Token Entropy）将悬崖 token 分为三类：
1. **确定性悬崖（Deterministic）**：贪婪 token + 低熵（H < 0.0561 nats）；模型近乎确信地选择该失败 token。
2. **不确定性悬崖（Uncertain）**：贪婪 token + 高熵（H ≥ 0.0561）；模型在高不确定下仍选了该 token。
3. **采样偏移悬崖（Sampled-off）**：非贪婪 token + 高熵；模型随机采样到一个低概率 token 导致失败。

### 2.4 Cliff-DPO 训练方法
- 在识别出的悬崖 token 位置：将**非悬崖 token**（非失败触发）作为“选择”，将原始悬崖 token 作为“拒绝”，构建单 token 级偏好对。
- 使用 DPO 损失，仅在这些特定 token 位置进行梯度更新，减少数据稀疏性并精确定位失败信号。

## 3. 实验设计
### 3.1 数据集与基准
- **GSM1K**（100题抽样）、**MATH500**（100题抽样）、**AIME 2025**（全部30题），共230个问题。
- 共用 **7个模型**：Qwen3-8B/4B/0.6B、Llama-3.1-8B/3.2-3B/1B、Gemma-3-4B（均为指令微调版本）。
- 每个模型在每个问题上生成一条推理轨迹，共1,610条轨迹用于分析。

### 3.2 对比方法
- **Cliff-del vs. Cliff-keep**：删除首个悬崖 token 后重采样 vs. 保留该 token 继续生成，计算 pass@k 恢复能力。
- **Cliff-DPO 对比基线**：原始 Qwen3-0.6B、标准 DPO、cDPO（Lin et al. 2025）。
- **消融**：不同悬崖类型（确定性、不确定性、采样偏移）分别训练；控制更新 token 数量的匹配实验；跨模型转移实验（Qwen3 家族内部）；不同熵阈值敏感性。

## 4. 资源与算力

## 5. 实验数量与充分性
- **主要实验**：涵盖7个模型、3个数据集，共1,610条轨迹的 token-wise potential 分析，计算量合理但已受限于成本。
- **消融实验**：
  - 删除/保留悬崖 token 对比（pass@k 曲线）。

  - 跨模型规模转移（Qwen3-0.6B ↔ 8B；Llama-3.2-1B ↔ Llama-3.1-8B）。
  - 熵阈值敏感性（p1=0.90/0.95/0.99/0.999）。
  - 更新 token 数量匹配控制（5,538个 token 等量训练）。
- **评估充分性**：实验设计较全面，涵盖了不同类型悬崖的区分、跨模型泛化、训练信号有效性验证。但由于计算限制，子采样了 GSM1K 和 MATH500 的数据集，且 Cliff-DPO 仅在 Qwen3-0.6B 上训练，泛化性验证不完整。总体而言，实验在可控资源下具有较强的内部有效性，外部泛化有待扩展。

## 6. 主要结论与发现
1. **悬崖 token 充当失败触发点**：删除首个悬崖 token 后重采样，pass@64 恢复至 **1.0**；保留则恢复率仅 **0.71–1.00**，表明该 token 是因果性触发点。
2. **三类悬崖概率特征不同**：
   - 确定性悬崖质量约1.0，跨模型规模几乎不变。
   - 不确定性悬崖质量分布宽（均值0.68），跨模型转移后质量普遍下降，反映模型特有知识缺口。
   - 采样偏移悬崖质量低（均值0.32），跨模型转移表现出尺度不对称性（小模型倾向于给大模型的采样偏移悬崖更高概率）。
3. **悬崖分类可泛化**：在 Qwen3 家族内部，确定性悬崖为尺度不变；不确定性悬崖为模型特有；采样偏移悬崖呈现尺度不对称。
4. **Cliff-DPO 优化效果取决于悬崖类型**：不确定性 + 采样偏移组合训练在 GSM1K 和 MATH500 上提升显著（最高 +5.9），而确定性悬崖训练几乎无效。
5. **效率优势**：Cliff-DPO 仅使用约 **3.3万** 个参与 loss 的 token 位置，即达到或超越 cDPO（使用近 **583万** token 位置），且训练时间从112分钟缩短至8分钟。

## 7. 优点
- **单 token 粒度定位**：首次精确识别导致失败转向的**起始 token**，而非失败已发生后的晚期标记。
- **自适应阈值**：基于统计检验而不是固定阈值，减少噪声误判，提高可靠性。
- **可解释分类**：依据贪婪性和熵将失败触发点分为三类，揭示了不同失败机制，并验证其在不同模型间的可迁移性。
- **高效的训练信号**：Cliff-DPO 使用极少 token 即取得显著提升，展示了从分析到优化的直接应用价值。
- **计算资源公开透明**：详细报告了 GPU 小时、数据集、采样参数，便于复现。

## 8. 不足与局限
- **计算成本高**：token-wise potential 估计需要大量 rollout（O(NT²)），即便用了子采样，仍是主要瓶颈。
- **子采样偏差**：GSM1K 和 MATH500 仅各取100题，可能不足以代表完整数据集；AIME 2025 仅30题。
- **模型和领域受限**：Cliff-DPO 仅在 Qwen3-0.6B 上训练，未验证到更大模型或非数学推理任务；跨模型转移实验仅限同一模型家族（Qwen3、Llama 3），未跨家族比较。
- **低估模型能力界限问题**：若问题完全超出模型能力（potential 初始即接近0），则无法检测到 cliff token，框架失效。
- **仅依赖 rollout 估计**：缺乏非 rollout 的预测方法，未来方向是开发轻量级 cliff token 检测器。
- **未报告多次运行的标准差**：部分图表（如 pass@k 曲线）仅展示单次运行结果，统计稳定性有待强化。
