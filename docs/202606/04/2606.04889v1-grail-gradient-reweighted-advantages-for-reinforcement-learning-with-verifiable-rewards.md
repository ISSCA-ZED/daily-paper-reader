## 摘要
基于可验证奖励的强化学习（例如GRPO）现在已成为改进大型语言模型（LLM）数学推理能力的常用方法。然而，当前方法通常将一个序列级别的优势广播到所有token，或使用昂贵的过程奖励模型（PRM）进行步骤级监督。均匀的优势分布假设所有token对最终奖励的贡献相同，这稀释了梯度信号，因为错误的推理步骤和填充词与有效的逻辑推理被同等强度地更新。为解决此问题，我们提出了梯度重加权优势（GRAIL），一种内在的逐token优势重加权方法。GRAIL利用梯度激活显著性，对局部对最终答案更敏感的token赋予更大权重。在来自Qwen3、R1-distilled和OctoThinker系列的五个模型上的评估表明，GRAIL始终优于GRPO。GRAIL在准确率上平均提升3.60%，在Pass@3上平均提升3.05%，表明无需过程级监督即可实现细粒度的推理对齐。

## Abstract
Reinforcement learning with verifiable rewards (e.g. GRPO) is now a common way to improve mathematical reasoning in Large Language Models (LLMs). However, current methods usually broadcast one sequence-level advantage to all tokens, or use costly process reward models (PRMs) for step-level supervision. Uniform advantage distribution assumes that all tokens contribute equally to the final reward. This dilutes the gradient signal, since flawed reasoning steps and filler words are updated as strongly as valid logical inferences. To address this, we introduce Gradient-Reweighted Advantage (GRAIL), an intrinsic token-wise advantage reweighting method. GRAIL uses gradient-activation saliency to place more weight on tokens that are more locally sensitive to the final answer. Evaluations across five models from the Qwen3, R1-distilled and OctoThinker families show that GRAIL consistently outperforms GRPO. GRAIL achieved an average improvement of 3.60% in accuracy and 3.05% in Pass@3, demonstrating that fine-grained reasoning alignment can be achieved without process-level supervision.

## 1. 核心问题与整体含义（研究动机和背景）
当前基于可验证奖励的强化学习（如 GRPO）在提升大语言模型数学推理能力方面广泛应用，但存在一个关键缺陷：**对所有 token 分配相同的序列级优势**，假设每个 token 对最终奖励的贡献相同。这导致：
- 错误推理步骤和填充词（如格式符号、无意义词语）与关键逻辑推理被同等更新，**梯度信号被稀释**。
- 模型难以区分哪些 token 真正驱动了正确结果，造成学习效率低下。
  
作者旨在**无需过程奖励模型（PRM）**的情况下，实现细粒度的逐 token 信用分配，从而在不增加外部监督成本的前提下提升推理对齐。

## 2. 论文提出的方法论
- **核心思想**：利用模型自身的梯度信息计算每个 token 对最终答案的**局部敏感性**，据此重加权序列级优势，使更重要的 token 获得更大更新。
- **关键技术细节**：
  1. **梯度-激活显著性**：
     - 将输入嵌入 \( e_t \) 作为可微分叶节点。
     - 计算答案损失 \( L_{\text{ans}} \)（答案 token 的负对数似然）对 \( e_t \) 的梯度。
     - 原始显著性得分：\( s_t = \| \frac{\partial L_{\text{ans}}}{\partial e_t} \odot e_t \|_2 \)。
  2. **标准化与裁剪**：
     - 对 \( s_t \) 取对数变换（\( \tilde{s}_t = \log(s_t + \epsilon) \)）以减轻长尾分布影响。
     - 标准变为 \( z \) 分数后线性缩放至指定范围：\( w_t = w_{\text{mean}} + \frac{\tilde{s}_t - \mu_{\log}}{\sigma_{\log}} \cdot \sigma_w \)，并裁剪至 \( [w_{\min}, w_{\max}] \)。
  3. **特殊 token 修正**：
     - 最终答案 token：权重设为 \( w_{\max} \)，保持正确性信号。
     - 答案定界符（如 \boxed{）：权重设为 \( w_{\text{mean}} \)，避免强化格式。
     - 答案后的 token（包括 EOS）：权重设为 \( w_{\text{mean}} \)，保持终止不确定性。
  4. **集成到策略梯度**：权重经 `stop_gradient` 后乘到 GRPO 的 min-clip 项中，形成新的目标函数 \( L_{\text{GRAIL}} \)，避免二阶导数干扰。
- **优势成分**：仅需一次前向 + 一次后向传播，显著低于 OAR（论文对比方法）所需的多步计算。

## 6. 主要结论与发现
- **性能提升**：GRAIL 相对于 GRPO 在所有模型和大多数基准上一致提升，**平均准确率 +3.60%**，**Pass@3 +3.05%**。在挑战性最高的 AIME 2024 上提升尤为显著（如 Qwen3-8B 从 36.67% 到 47.78%）。
- **与 OAR 对比**：GRAIL 显著优于 OAR-G（Qwen3-8B 准确率 62.04% vs 55.75%），表明直接使用**分析梯度**比噪声注入代理更有效。
- **权重分布分析**：
  - 正确 rollout：权重在推理中间段均匀且接近基线，说明正确步骤贡献分布广。
  - 错误 rollout：权重在中间段保持较高，推测集中在逻辑错误位置，说明负向信号对纠正错误更重要。
- **对称 vs 非对称加权**：仅在错误 rollout 上应用 GRAIL 获得最好结果，但对称应用（所有 rollout）稳定性更高，被选为主版本。
- **无需过程监督**：仅使用序列级奖励 + 内在梯度即可实现 token 级信用分配。

## 7. 优点
- **轻量无监督**：无需训练额外的过程奖励模型或依赖外部标注，完全利用模型自身梯度。
- **计算高效**：仅额外一个反向传播，远低于集成梯度或噪声注入方法。
- **可解释性**：权重分布可定位错误步骤，提供推理诊断。
- **泛化性**：跨不同模型系列和参数量一致有效。
- **理论稳健**：通过 stop-gradient 确保策略梯度估计正确，且权重设计（对数变换、裁剪、特殊 token 修正）保证训练稳定。

## 8. 不足与局限
- **近似局限**：基于一阶梯度 × 激活的显著性仅为线性近似，无法捕捉 token 间非线性交互或反事实贡献（如联合贡献）。
- **计算开销**：训练时间增加约 50–60%，对于更大模型或资源受限场景可能较重。
- **领域局限**：仅在数学推理任务验证，未扩展到其他可验证领域（如代码生成、逻辑推理）。
- **对比覆盖不足**：未与基于 PRM 的方法（如 Math-Shepherd）或更复杂的 token-MDP 方法（如 Rudder）直接比较。
- **风险**：
  - **过度依赖梯度信号**：若模型陷入局部最优或梯度噪声大，可能不准确。
  - **特殊 token 修正依赖先验**：答案标记、EOS 的权重设定需要人工规则，可能不适用于其他格式或早期停止场景。
- **统计力度**：虽然 Wilcoxon 检验显著，但未报告置信区间或细分到每个任务的重复性。
