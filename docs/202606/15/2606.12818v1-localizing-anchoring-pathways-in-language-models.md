## 摘要
提示中的无关数字会改变语言模型的判断，从而在数值推理中产生锚定效应。我们通过使用共享答案选项的受控多项选择设置，研究了这种锚定敏感信号在语言模型内部传递的位置。我们定义了一个对数几率差指标，比较正确答案选项与对应于锚点的答案选项，并验证了它能够追踪行为锚定。在7B-8B Qwen和Llama基础模型及指令微调模型上使用基于归因的电路定位，我们发现边级方法比节点级方法更忠实地恢复了这种信号。低锚定和高锚定电路在模型内部具有很强的转移性，表明在锚定方向上存在共享的路径结构。然而，在基础模型和指令微调变体之间的稀疏转移不太可靠，表明后训练改变了哪些路径最为重要。总体而言，我们的结果提供了一个关于锚定相关决策信号如何在语言模型内部传递的机制性解释。

## Abstract
Irrelevant numbers in a prompt can shift language model judgments, producing anchoring effects in numerical reasoning. We study where this anchor-sensitive signal is carried inside language models using a controlled multiple-choice setup with shared answer options. We define a logit-difference metric comparing the correct answer option with the answer option corresponding to the anchor, and validate that it tracks behavioral anchoring. Using attribution-based circuit localization on 7B--8B Qwen and Llama base and instruction-tuned models, we find that edge-level methods recover this signal more faithfully than node-level methods. Low- and high-anchor circuits transfer strongly within a model, suggesting shared pathway structure across anchor direction. However, sparse transfer across base and instruction-tuned variants is less reliable, indicating that post-training changes which pathways matter most. Overall, our results provide a mechanistic account of how anchoring-related decision signals are carried inside language models.

#### 2. 提出的方法论

- **核心思想**：将不可见的数值推理锚定效应，转化为一个可在模型内部追踪的、定义清晰的信号——即**正确答案与锚定答案之间的竞争**。通过识别并验证承载该信号的神经通路，从机制上解释锚定效应。
- **关键技术细节**：

    2.  **代理指标定义**：
        - **行为指标**：使用期望值偏移和总变分距离来测量锚定效应。
        - **归因指标**：定义一个标量度量 `m = logit(y_correct) - logit(y_anchor)`，即正确答案与锚点答案的logit差值。`m` 值越小，表示锚点答案的竞争性越强。

        - 将Transformer模型视为一个计算图，节点是组件（注意力头、MLP），边是组件间的连接通路。
        - 使用**归因补丁**类方法，比较“干净输入”（无锚点控制提示）和“损坏输入”（含锚点提示）来计算每个节点或边对 `m` 的贡献。
        - 对比了四种方法：节点级归因补丁（NAP）、边级归因补丁（EAP）及其各自的集成梯度变体（NAP-IG, EAP-IG）。

#### 6. 主要结论与发现

1.  **边级方法优于节点级方法**：EAP和EAP-IG在恢复锚定信号方面，其忠实度（CPR）**显著高于**NAP和NAP-IG。这表明锚定效应更可能通过组件间的特定通路传播，而非单个孤立的“偏见”组件。
2.  **EAP-IG是最忠实的方法**：在大多数模型和锚定方向上，EAP-IG的忠实度最高，是后续分析的首选方法。
3.  **锚定电路定位存在家族差异**：
    - **Qwen模型**：锚定相关通路集中于中后期层。

4.  **低锚和高锚使用高度相似的通路**：在同一模型内，低锚和对应的控制提示、高锚和对应的控制提示之间的对比，其定位出的电路在**层深度分布**和**组件组成**上高度重合，且可以很好地进行**功能迁移**。这表明它们共享一个通用的“锚定敏感”通路。
5.  **指令微调改变了稀疏通路结构**：基础模型和指令微调模型的电路在**宏观层深度**上相似，但在**具体的稀疏边集合**上存在显著差异。因此，从基础模型到指令微调模型的电路*功能迁移*（特别是小电路时）不如低高锚之间的迁移可靠，说明后训练过程改变了哪些稀疏通路最为关键。
6.  **锚定涉及注意力-MLP交互**：定位出的电路（特别是前5%的边）中，注意力-MLP之间的连接比例显著高于全图中的比例，暗示MLP通过参与注意力介导的通路来起作用。

#### 7. 优点

- **方法论创新**：成功地将认知心理学中的“锚定效应”转化为一个可进行**机械可解释性分析**的受控任务和可追踪的标量指标。这是将可解释性工具应用于研究高维认知偏差的典范。

#### 8. 不足与局限

- **任务人为性**：使用了**多项选择格式**和较少的选项（9个），这与模型在实际开放式数值推理任务中的行为存在差异。锚定效应的内部机制在开放式生成中可能不同。
